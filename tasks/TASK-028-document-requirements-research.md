# TASK-028 — บันทึกข้อเสนอเอกสารสินค้า/ลูกค้าและคำตอบ OPEN-10/14

**สถานะ:** READY_FOR_USER_TEST

**Specs:** [ข้อบันทึก OPEN-10/14 เบื้องต้น](../docs/specs/2026-09-25-open10-open14-preliminary-amendment.md)

**Plan:** [แผนย่อย](../docs/plans/2026-09-25-document-requirements-research-plan.md)

**ขอบเขต:** เลือก/บันทึกเพดานไฟล์ที่ผู้ใช้มอบหมาย, บันทึกคำตอบเพิ่มเกี่ยวกับ Audit, Role และ Admin, ค้นหลักฐานทางการเพื่อเสนอรายการเอกสารสินค้า/ลูกค้า. ข้อเสนอเรื่องเอกสารยังไม่กลายเป็น required fields หรือกฎกฎหมายของระบบ.

**ไฟล์:** Specs amendment, DECISIONS, Project Plan, Handoff, Task นี้, ACTIVE และ COMPLETED.

**ผลตรวจ:** บันทึกแหล่งทางการไทยสำหรับการอนุญาตผลิต/นำเข้า/ขายยาและใบอนุญาตสถานพยาบาล; ตรวจเอกสาร Supabase Storage ว่าเพดาน 20 MiB ทำได้ภายใต้ Free limit 50 MB และแนะนำ Resumable Upload เมื่อเกิน 6 MB. ไม่มีการแก้โค้ด/ฐานข้อมูล.

## ⚠️ ต้องทดสอบโดยคุณ

1. อ่านตารางข้อเสนอใน Specs amendment แล้วตรวจว่าแยกเอกสารสินค้า, ผู้ผลิต/ผู้นำเข้า, Lot/Shipment และลูกค้าตามชนิดถูกต้อง
2. ยืนยันว่าข้อเสนอใดควรเป็นเอกสารบังคับ โดยเฉพาะลูกค้าโรงพยาบาล/คลินิกและร้านยา; ถ้ายังไม่แน่ใจให้คงเป็นข้อเสนอและปรึกษาเภสัชกร/ฝ่ายกำกับดูแล
3. ตรวจว่าบันทึก 20 MiB ต่อไฟล์และ Role 1 คนต่อ 1 Role ตรงกับที่ต้องการ; จุดเริ่มนับ Audit และวิธีจัดการ Admin คนสุดท้ายยังคง OPEN
4. ผลที่ควรเห็น: ข้อเสนอไม่ถูกแปลงเป็น validation/กฎระบบ; G-04/G-10 ยังคงไม่ผ่านจนกว่าจะตัดสินใจประเด็นค้าง
