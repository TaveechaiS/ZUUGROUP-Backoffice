## ขอบเขต

สำรวจและบันทึกว่าหน้าใดเป็น DB จริง หน้าใดยังใช้ข้อมูล Mock และ dependency ของแต่ละชุด เพื่อเปิด Task รายโมดูลตามกฎที่เจ้าของโครงการอนุมัติ งานนี้ไม่เปลี่ยน schema, API, UI หรือข้อมูลใน DB

## ผลตรวจ

ผู้ใช้/สินค้าใช้ DB แล้ว; Dashboard และหน้ารายการ 19 URL ยัง Mock โดยหน้าเพิ่มของชุดนี้เก็บใน `sessionStorage`. Prisma ยังไม่มีตารางธุรกิจของลูกค้า ผู้ขาย เอกสารซื้อ/ขาย ค่าใช้จ่าย สต็อก หรือการเงิน

## การตรวจรับ
