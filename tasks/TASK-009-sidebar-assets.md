## ขอบเขต

- บันทึก SVG icons จากผู้ใช้เป็นไฟล์ asset แยก โดยคงขนาดและ path ที่ให้
- ปรับ Sidebar ให้ใช้เฉพาะชื่อเมนูและกลุ่มที่ผู้ใช้ระบุ
- ใช้ Wordmark แบบข้อความตาม style ที่ผู้ใช้ส่ง
- ลบไอคอนและสัญลักษณ์โลโก้ที่ AI วาดขึ้นเอง
- คง placeholder routes และหน้า Dashboard ว่าง

## แผนย่อยและลำดับดำเนินการ

1. ตรวจ `tasks/ACTIVE.md` และยืนยันรายการไฟล์ในขอบเขต Task นี้
2. บันทึก SVG/กลุ่ม/ป้ายเมนูที่เจ้าของโครงการส่งลง Specs; ตรวจไฟล์ asset ให้ตรงกับข้อความต้นทาง
3. ใช้เฉพาะรายการที่ยืนยันใน Sidebar และผูกกับ placeholder routes ที่มีอยู่
4. เปลี่ยน Wordmark เป็นข้อความตาม style ที่ระบุ และเอาเครื่องหมาย/ไอคอนที่ AI วาดเองออก
5. ตรวจ lint, type-check, build และภาพ Sidebar ทั้งสถานะย่อ/ขยายก่อนส่งให้ผู้ใช้ตรวจ

งานนี้ยังไม่มีการอนุมัติให้เพิ่มโมดูล CRUD, ข้อมูลจำลอง หรือเปลี่ยนกฎธุรกิจ

## การอนุมัติและประเด็นที่ยังเปิด

- เจ้าของโครงการอนุมัติ Specs รุ่น 0.3 และ Plan รุ่น 0.2 เมื่อ 2026-09-24
- OPEN-16 ไม่ขวางการใช้เมนูที่ระบุแล้ว; โมดูลที่ยังไม่มีตำแหน่งใน Sidebar จะไม่ถูกเพิ่มจนกว่าจะยืนยัน

## ผลที่ทำและตรวจแล้ว

- คัด SVG ทั้ง 13 ไฟล์จากข้อความแนบโดยตรงและเปรียบเทียบเนื้อหาไฟล์กับข้อความต้นฉบับ: ตรง 13/13
- Sidebar แสดงเฉพาะ 13 เมนูใน 5 กลุ่มตาม Specs §6.5; Wordmark เป็นข้อความตาม style ที่ระบุ; นำ SVG ที่ AI วาดเองออก
- `npm run lint`, `npm run type-check` และ `npm run build` ผ่าน
- เปิดหน้า `/customers/dashboard` และกดเมนู `ตั้งค่าระบบ` ไป `/settings` ได้ในเบราว์เซอร์ขนาดแคบ
- ยังต้องให้เจ้าของโครงการตรวจภาพ Desktop และการย่อ/ขยาย Sidebar ตามรายการด้านล่าง

- กดปุ่มย่อ/ขยาย Sidebar: แถบเมนูหลักต้องสลับระหว่างข้อความกับแถบไอคอน และเมนูรองต้องแสดงรายการลูกค้า
