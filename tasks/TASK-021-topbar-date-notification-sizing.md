# TASK-021 — ปรับวันที่ การแจ้งเตือน และโปรไฟล์ผู้ใช้ใน Topbar

**สถานะ:** DONE

**Specs:** [วันที่ การแจ้งเตือน และโปรไฟล์ผู้ใช้ใน Topbar](../docs/specs/2026-09-24-topbar-date-notification-sizing.md)

**Plan:** [แผนสั้น](../docs/plans/2026-09-24-topbar-date-notification-sizing-plan.md)

**ขอบเขต:** ชื่อหน้า 20px บน Desktop (`text-xl`) และ 18px บนจอแคบ (`text-lg`); วันที่ 14px บน Desktop; ปุ่มแจ้งเตือน 36px และไอคอน 18px บน Desktop, ย่อปุ่มเป็น 24px และไอคอน 14px บนจอแคบตาม Specs. ปรับวงกลมโปรไฟล์ผู้ใช้เป็น 36px บน Desktop และ 24px บนจอแคบให้เท่าปุ่มแจ้งเตือน; ขยายจุดสีแดงบนไอคอนกระดิ่งจากรัศมี 3 เป็น 4 หน่วย SVG; แทนตัวอักษรลูกศรโปรไฟล์ด้วย SVG ที่เจ้าของโครงการส่งมา; คงชื่อ บทบาท และตำแหน่งอื่นใน Topbar.

**ไฟล์:** `src/components/layout/admin-shell.tsx`, Specs/Plan/Task และ `tasks/ACTIVE.md`.

**ผลตรวจ:** TypeScript type-check และ `git diff --check` ผ่าน; path, สี, น้ำหนักเส้น และขนาด SVG ตรงตามที่ส่งมา.

## ⚠️ ต้องทดสอบโดยคุณ

- รีเฟรชหน้าบน Desktop แล้วตรวจว่าชื่อหน้ามีขนาด 20px และวันที่มีขนาด 14px.
- ตรวจว่าปุ่มกระดิ่งและไอคอนเล็กลงอีกเล็กน้อย จุดแจ้งเตือนสีแดงใหญ่ขึ้นและยังอยู่ในไอคอน และตัวแบ่งส่วน/โปรไฟล์ไม่ขยับผิดตำแหน่ง.
- วงกลมโปรไฟล์ผู้ใช้ควรมีขนาดเท่าปุ่มแจ้งเตือน; ชื่อ บทบาท และลูกศรยังแสดงตามเดิม.
- ลูกศรข้างโปรไฟล์บน Desktop เป็น SVG ที่ส่งมา โดยรูปทรง สี และขนาดตรงต้นฉบับ.
- ตรวจจอแคบภายหลังในรอบ Responsive.

**ผล UAT:** เจ้าของโครงการยืนยันว่าผ่านทั้งหมดเมื่อ 2026-09-25.
