## ขอบเขต

บันทึกคำยืนยันว่าใช้ Supabase Cloud ปัจจุบันเป็น DB ทดสอบที่เก็บข้อมูลตัวอย่างจริง และเริ่มจากข้อมูลหลักสินค้า (รหัส ชื่อ หมวด หน่วย ราคา สถานะ) โดยรหัสสร้างจากหมวดหมู่ยา-รูปแบบยา-เลขลำดับ ตามคำตอบล่าสุดที่แทนแนวชื่อ-ปีเดิม. งานนี้เป็นการเตรียมขอบเขต; งาน schema/API/UI แต่ละโมดูลต้องมี Specs/Task ย่อยที่อนุมัติก่อน

## ผลลัพธ์ที่ต้องได้

- ลำดับโมดูลแรกและกฎรหัส/ฟิลด์ขั้นต่ำได้รับคำตอบ
- สถานะ OPEN/Gate ไม่ถูกนับว่าปิดเพียงเพราะใช้ข้อมูลจำลองใน DB
- งานย่อยแรกมี Specs, Plan, ไฟล์, วิธีตรวจ และขอบเขต migration ชัดก่อนเริ่ม code

## ⚠️ ต้องทดสอบโดยคุณ

ตรวจแผนว่า Supabase project ปัจจุบันเป็นที่เก็บข้อมูลทดสอบ และขอบเขตโมดูลแรกตรงที่ต้องการ; ผลที่ควรเห็นคือรายการที่ยังรอกฎถูกแยกไว้ชัด ไม่กลายเป็นคำสั่งเปลี่ยนยอดหรือสิทธิ์จริงโดยอัตโนมัติ
