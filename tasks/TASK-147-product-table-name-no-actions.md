# TASK-147 — ชื่อสินค้าไม่มีรูปและไม่มีจัดการ

สถานะ: DOCUMENTED / WAITING_FOR_UAT; อนุมัติจากคำขอเจ้าของ 5 ตุลาคม 2569

ผลตรวจ: ตารางจริงแสดง product.name เป็นข้อความ ไม่มีรูปหรือคอลัมน์จัดการ และยังกดแถวเปิดรายละเอียดได้ตามโค้ด. เอกสารตรงข้อยืนยันแล้ว git diff --check ผ่าน ไม่แก้โค้ด ยังไม่ตรวจภาพจริงในเบราว์เซอร์.

## แผนย่อย

1. อ่าน ACTIVE/Specs/Plan และตรวจตาราง product-stock-list.tsx.
2. บันทึกข้อยืนยันชื่อสินค้าเป็นข้อความไม่มีรูปเล็ก และไม่มีคอลัมน์จัดการ/เครื่องมือใน Specs/Plan.
3. ปรับ docs/designs/stock-screen-design.md ให้ตรงข้อยืนยัน คงการกดแถวเปิดรายละเอียด. ตารางจริงตรงแล้วจึงไม่แก้โค้ดหรือคอลัมน์อื่น.
4. ตรวจ git diff --check และตรวจหัวตาราง/เซลล์ชื่อสินค้า บันทึกผล.

ไฟล์ที่เปลี่ยน: tasks/ACTIVE.md, Specs/Plan หลัก, docs/designs/stock-screen-design.md และ Task นี้. ผลลัพธ์: ข้อกำหนดตารางสอดคล้องคำขอ ไม่มีรูปเล็กและคอลัมน์จัดการ.
