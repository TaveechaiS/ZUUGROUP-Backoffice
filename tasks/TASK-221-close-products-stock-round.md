# TASK-221 — ปิดรอบงานสินค้าและสต็อก

OWNER_CLOSED_CURRENT_ROUND — 6 ตุลาคม 2569

เจ้าของให้ปิดงานหน้าสินค้าและสต็อกรอบนี้ และจะกลับมาอัปเดตข้อมูลอีกครั้ง. ปิดรอบการทำงาน ไม่ถือว่ารายการตรวจรับหรือข้อผิดพลาดค้างผ่านแล้ว.

## แผนย่อยและขอบเขต

1. อ่าน ACTIVE/Specs/Plan/HANDOFF และ git status เพื่อสรุปสถานะจริง.
2. บันทึกคำสั่งปิดรอบและงานค้างใน ACTIVE/Specs/Plan/HANDOFF/Task นี้.
3. ตรวจ diff เอกสาร แล้วจบรอบ รอข้อมูล/คำสั่งเจ้าของครั้งถัดไป.

เปลี่ยนเอกสารเท่านั้น ไม่แก้โค้ด/ข้อมูล/Schema. ไม่ commit/push/deploy ในคำขอนี้.

## งานที่มีแล้ว

- หน้ารายการสินค้า เพิ่มสินค้า รายละเอียด/แก้ไข ประวัติ รูป/เอกสาร และข้อมูลพื้นฐานสินค้า.
- หน้าคลังหลัก/การตลาด/รอทำลาย เติมสต็อก ประวัติและรายละเอียดรับเข้า.
- TASK217: คิว query ต่อ transaction แก้ pg warning จาก relation reads; offline concurrency/error และ DB READ ONLY 3รอบไม่พบ warning. รอ browser UAT.
- TASK218–219: เปลี่ยนชื่อหมวดเป็นสินค้า/สต็อกและข้อความเกี่ยวข้อง.
- TASK220: เมนูหลักสินค้า → สต็อก ลำดับทั้ง4Role และเมนูไม่ซ้ำผ่าน. รอ browser UAT.
- งานข้อมูลคลังในตั้งค่าถูกเจ้าของย้อน ไม่มี route/menu เพิ่มดังกล่าว.

## เก็บไว้สำหรับรอบถัดไป

- ผลอ่าน DB วันที่6ตุลาคม: สินค้า13รายการ ข้อมูลพื้นฐานรหัส/ชื่อ/หน่วย/ราคาครบ แต่12รายการไม่มี full profile และไม่มีไฟล์แนบ. ต้องรับข้อมูลจริงจากเจ้าของ ไม่เติมโดยเดา.
- Generated Prisma ยังไม่มี details/codeGroupId ตาม Schema และ generated Next route types ขัดกัน จึง TypeScript ยังไม่ผ่าน. ตรวจ/generateใหม่อย่างเหมาะสมเมื่อเริ่มงานแก้.
- src/app/products/page.tsx และ products/stock/[warehouse]/page.tsx คำนวณ pages ด้วย total/10 แม้เลือก pageSize อื่น ต้องแก้ให้ใช้ pageSize ในงานต่อไป.
- หน้าสินค้าปัจจุบันไม่มีปุ่มลบ/กู้คืน/ส่งออกหรือแท็บลบแล้ว แม้ APIลบ/กู้คืนมีแล้ว; ไม่เพิ่มเปิดปิดขายที่เจ้าของไม่ได้ขอ.
- รายงานสรุปคงเหลือ/ความเคลื่อนไหว/ใกล้หมดอายุ/คงเหลือต่ำ/ผลตรวจนับ และยอดขายตามสินค้า ยังเป็นหน้ารอเชื่อมข้อมูล. ทบทวนขอบเขตที่อนุมัติและ OPEN ก่อนทำ.
- ประวัติสินค้าปัจจุบันกรองเฉพาะ PRODUCT_CREATED_FULL/PRODUCT_UPDATED_FULL; ไม่ถือว่ารวมประวัติ legacy/ลบ/กู้คืนทั้งหมดแล้ว.

ข้อค้นพบเหล่านี้เป็น backlog ไม่ใช่อนุมัติให้เริ่มทุกข้อทันที. ตรวจสถานะใหม่ก่อนทำต่อเพราะข้อมูลจริงอาจเปลี่ยน.
