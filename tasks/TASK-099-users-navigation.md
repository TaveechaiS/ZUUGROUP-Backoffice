# TASK-099 — เมนูผู้ใช้งานแทนจัดซื้อ

สถานะ IMPLEMENTED / WAITING_FOR_UAT; เจ้าของอนุมัติด้วยคำสั่ง “ลบ จัดซื้อ & รับเข้าสต็อก ออกและ แทนด้วย ผู้ใช้งาน” 5 ตุลาคม 2569.

ผลตรวจ: ESLint navigation.ts, route checks 62 หน้า และ diff whitespace ผ่าน. ยังไม่ได้ตรวจหน้าจอหลัง login; รอเจ้าของตรวจรับตามด้านล่าง.

## ลำดับ ผลลัพธ์ และไฟล์

1. บันทึกข้อกำหนดใน tasks/ACTIVE.md, เอกสารนี้ และ Specs/Plan หลัก.
2. src/config/navigation.ts: ซ่อนรายการ /purchases จาก Sidebar หลัก; ย้าย /users ไปตำแหน่งเดิมในหมวดจัดการข้อมูล ใช้ชื่อและไอคอนผู้ใช้งาน ไม่มีรายการซ้ำ.
3. ตรวจ ESLint เฉพาะไฟล์, route checks และ diff whitespace; คงการกรองสิทธิ์ Admin เดิมและรายการรับสินค้าเข้าใต้สินค้าและสต็อก.

## ⚠️ ต้องทดสอบโดยคุณ

- Admin: Sidebar แสดงผู้ใช้งานแทนจัดซื้อ & รับเข้าสต็อกเพียงครั้งเดียว กดแล้วเปิด /users; หน้าเพิ่มและรายละเอียดผู้ใช้ยังเลือกเมนูผู้ใช้งาน.
- ย่อ Sidebar และเปิดมือถือ: เมนูผู้ใช้งานยังเปิดหน้าเดิมได้.
- Role อื่น: ไม่เห็นเมนูผู้ใช้งาน. เมนูรับสินค้าเข้าใต้สินค้าและสต็อกยังเปิดหน้าเดิมได้.
