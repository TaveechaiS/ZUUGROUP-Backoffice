ตรวจและปรับ environment เฉพาะในเครื่อง โดยไม่บันทึกค่า credential ในเอกสารหรือ Git. ไม่เปลี่ยนรหัสผ่านฐานข้อมูลที่เจ้าของจะดูแลเอง.

ผลตรวจ: ตัวแปร Supabase ที่แอปใช้มีค่า, `DATABASE_URL` ผ่าน `SELECT 1`, `.env.local` ถูก Git ignore, เจ้าของยืนยัน Login ใช้ได้. `DIRECT_URL` ไม่มีหลังเจ้าของวางค่าใหม่; ต้องเติม direct connection string ก่อน Prisma migration ซึ่งไม่อยู่ในขอบเขต Login.

## ⚠️ ต้องทดสอบโดยคุณ

หลังทำ: เปิดหน้า Login ควรไม่แสดงข้อความขาดการตั้งค่า; เข้าสู่ระบบด้วยบัญชีของคุณแล้วเปิดข้อมูลที่ต้องใช้ฐานข้อมูล. หากรหัสผ่านฐานข้อมูลที่คุณใส่เองไม่ถูกต้อง ระบบจะยังเชื่อม DB ไม่ได้.
