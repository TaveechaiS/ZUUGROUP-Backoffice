# TASK-010 — Logo และโปรไฟล์ใน Sidebar

| รายการ | รายละเอียด |
|---|---|
| Phase | 2 — UI และ Design foundation |
| ผู้รับผิดชอบ | AI |
| สถานะ | DONE |
| Branch | `ai` |
| ต้นทางคำขอ | เจ้าของโครงการส่ง `Logo.png` และขอให้ลบโปรไฟล์ Sidebar พร้อมระบุตำแหน่ง CSS ขนาดตัวอักษร |

## ขอบเขตและแผนย่อย

1. บันทึกข้อกำหนด Logo/โปรไฟล์ และแผนย่อยในไฟล์แก้ไขสั้นของ Specs/Plan
2. คัดลอกภาพ `Logo.png` ที่ผู้ใช้ส่งไป `public/logo.png` แล้วแสดงใน Sidebar ทั้งสถานะขยายและย่อ
3. ลบบล็อกโปรไฟล์ท้าย Sidebar และ CSS ที่ใช้เฉพาะบล็อกนั้น โดยคงโปรไฟล์ใน Topbar
4. ระบุ selector, ขนาด และตำแหน่งไฟล์ของตัวอักษรทุกจุดใน Sidebar ให้ผู้ใช้ปรับต่อได้
5. ตรวจ lint/type-check/build และภาพหน้าเว็บที่เปิดได้ ก่อนส่งให้ผู้ใช้ตรวจ

## ผลที่ทำและตรวจแล้ว

- `public/logo.png` ตรงกับไฟล์ต้นฉบับ (SHA-256 เท่ากัน)
- แสดง Logo บน Sidebar แบบขยายและย่อ; ลบบล็อกโปรไฟล์ท้าย Sidebar โดยคงโปรไฟล์ใน Topbar
- `npm run lint`, `npm run type-check` และ `npm run build` ผ่าน
- ตรวจภาพหน้า `/customers/dashboard` บน Desktop ทั้งแบบขยายและย่อแล้ว: เห็น Logo และไม่เห็นบล็อกโปรไฟล์ท้าย Sidebar; เมนูรองแสดงเมื่อย่อ
- ปุ่มวงกลมตัว `N` ที่มุมจอขณะรัน `next dev` เป็นเครื่องมือของ Next.js ไม่ใช่โปรไฟล์ของ Sidebar

## ⚠️ ต้องทดสอบโดยคุณ

- เปิดหน้าเว็บบน Desktop: ต้องเห็น Logo ที่ส่งใน Sidebar และไม่เห็นบล็อกโปรไฟล์ท้าย Sidebar
- กดปุ่มย่อ/ขยาย Sidebar: ต้องเห็น Logo ทั้งสองสถานะ และเมนูเดิมยังเปิดได้

**ผล UAT:** เจ้าของโครงการยืนยันว่าผ่านทั้งหมดเมื่อ 2026-09-25.
