## ขอบเขต

- แยก Sidebar เป็น React component ที่ใช้ร่วมกันได้
- เชื่อมรายการเมนู Admin ไปยัง route ของแต่ละส่วน
- สร้างหน้า placeholder สำหรับหน้าใน Project Plan รวมถึงรายงานแยกประเภท
- สร้าง route placeholder ของหน้าลูกค้าตามตัวอย่าง: ภาพรวมลูกค้า, รายชื่อลูกค้า, กลุ่มลูกค้า, เขต/ผู้แทนขาย และเอกสารแนบ
- แสดงชื่อหน้า/เส้นทางปัจจุบันและข้อความระบุว่ายังไม่ได้เริ่มพัฒนาส่วนงาน
- คง Dashboard เป็น placeholder และใช้ primary color `#1A58A7`

## นอกขอบเขต

- CRUD, schema/migration, API, Auth/RBAC, ข้อมูลตัวอย่าง หรือการเขียน Cloud
- สรุป KPI/กราฟ/รายงานจริง หรือกำหนด workflow ที่อยู่ใน OPEN
- เพิ่ม Role `Inventory` หรือปรับแก้ Figma

## เกณฑ์พร้อมส่ง

- คลิกเมนู Sidebar แล้วเปิด route และหน้า placeholder ที่ตรงกับเมนู
- Sidebar แสดงสถานะหน้าที่กำลังเปิดและใช้งานซ้ำทุก route
- เมื่อย่อ Sidebar หน้าลูกค้าแสดงเมนูรองตามรายการในตัวอย่าง
- รองรับการเปิด URL โดยตรงและเส้นทางรายงานย่อย
- `npm run lint`, `npm run type-check`, `npm run build` ผ่าน

## ⚠️ ต้องทดสอบโดยคุณ

- เปิด `http://localhost:5000` แล้วคลิกเมนูแต่ละกลุ่ม ควรไปยัง URL และแสดงชื่อหน้าให้ตรงกัน
- รีเฟรชหน้า placeholder และเปิด URL โดยตรง ควรยังเห็น Sidebar พร้อมสถานะเมนูปัจจุบัน
- ย่อ/ขยาย Sidebar แล้วเปิดเมนูอื่น ควรรักษารูปแบบแถบหลัก และหน้าลูกค้าควรแสดงเมนูย่อยตามตัวอย่าง
- ย่อหน้าจอให้แคบแล้วตรวจว่าแถบเมนูเลื่อนแนวนอนได้ และเนื้อหาไม่ถูกตัด
