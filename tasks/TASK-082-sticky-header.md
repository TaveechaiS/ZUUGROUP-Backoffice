# TASK-082 — ล็อกแถบสีและ Header

สถานะ: COMPLETE

ผลล่าสุดตามคำยืนยัน “เอาการล็อก Header ตอนเลื่อนออก”: ถอน sticky/top/z-index จาก wrapper ใน admin-shell แล้ว. Header/แถบสีเลื่อนตามหน้าทั้ง desktop/mobile โดยยังแสดงข้อมูลและใช้ปุ่มได้เมื่ออยู่ต้นหน้า. Specs/Plan ตรงกับคำขอล่าสุด; ESLint เฉพาะไฟล์, type-check และ diff-check ผ่าน. เจ้าของตรวจโดยเลื่อนลงให้ Header พ้นจอและกลับต้นหน้า; ประวัติการทดลองล็อก Header ด้านล่างถูกแทนที่แล้ว.

คำขอและผลล่าสุด: เจ้าของขอกลับไปใช้ Header เหมือนเดิม จึงคืน sticky wrapper ที่ครอบ Header พร้อม border สีน้ำเงิน 10px แล้ว. Header ชื่อหน้า/วันที่/บัญชีและแถบสีติดด้านบนร่วมกัน; mobile ใต้เมนูหลัก. แก้ Specs/Plan ให้ตรงแล้ว; ESLint เฉพาะไฟล์และ type-check ผ่าน. ตรวจรับโดยเลื่อนหน้าทั้ง desktop/mobile แล้วต้องเห็น Header พร้อมแถบสีและปุ่มยังใช้ได้. ข้อความเรื่องติดเฉพาะแถบสีด้านล่างเป็นประวัติที่ถูกแทนที่แล้ว.

งานติดตามล่าสุด: เจ้าของขอให้ติดเฉพาะแถบสี 10px; Header เลื่อนพร้อมเนื้อหา. ปรับ Specs/Plan และแยกแถบ sticky เป็น element สูง 10px ก่อน Header ใน admin-shell แล้ว. Header อยู่ใน flow ปกติพร้อมพื้นหลังมุมโค้งเดิม. ESLint เฉพาะไฟล์, type-check แบบไม่เขียน cache, Prettier และ diff-check ผ่าน; ยังไม่ได้ตรวจภาพใน browser.

ตรวจรับล่าสุด: เลื่อนหน้าจน Header พ้น viewport ควรเหลือแถบสีด้านบน; บนมือถืออยู่ใต้เมนูหลัก. กลับต้นหน้าแล้วต้องเห็น Header และใช้ปุ่มได้. รายงานเดิมด้านล่างเป็นผลรอบก่อนคำยืนยันนี้.

เจ้าของขอเมื่อ 2026-10-03 ให้แถบสีเหนือ Header ติดด้านบนเวลาเลื่อนหน้า. อนุมัติจากคำขอโดยตรง.

ขอบเขต: `src/components/layout/admin-shell.tsx` และเอกสาร Specs/Plan/Task/ACTIVE. ลำดับและวิธีตรวจรับตาม [แผนย่อย](../docs/plans/2026-10-03-sticky-header-plan.md); ข้อกำหนดตาม [Specs](../docs/specs/2026-10-03-sticky-header.md).

ผล: ย้าย border สี 10px เข้า sticky wrapper ที่ครอบ Header. Desktop ติด top 0; mobile ติดใต้ Sidebar ที่ top 64px เมื่อย่อ / 102px เมื่อขยาย. พื้นหลัง wrapper สีน้ำเงินคงมุมโค้ง Header เดิม.

ผลตรวจ: จัดรูปแบบด้วย Prettier, ESLint เฉพาะไฟล์, `npx tsc --noEmit --incremental false` และ `git diff --check` ผ่าน. ยังไม่ได้ตรวจภาพใน browser; รอเจ้าของตรวจ desktop/mobile ด้วยการเลื่อนหน้าและย่อ/ขยายเมนู. ควรเห็นแถบสีพร้อม Header ตลอดการเลื่อนและกดปุ่มบน Header ได้.
