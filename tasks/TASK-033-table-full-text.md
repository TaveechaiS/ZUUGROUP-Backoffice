- **ผู้รับผิดชอบ:** AI

- **Specs:** Project Specs §22.12
**Plan:** [แผนย่อย](../docs/plans/2026-09-25-table-full-text-plan.md)

## ขอบเขต

เลิกตัดข้อความในหัวตาราง เซลล์ และการ์ดมือถือของหน้ารายการกับผู้ใช้งาน ให้ขึ้นบรรทัดใหม่ได้; คงสี กรอบ และการทำงาน.

## ผลดำเนินการ

- ลบ `truncate` และ `max-w-0` ในหัวตาราง/เซลล์; ใช้ `whitespace-normal` กับ `overflow-wrap:anywhere` เพื่อแสดงข้อความเต็มและรองรับคำยาว.
- การ์ดมือถือแสดงชื่อ ผู้รับผิดชอบ ค่า และข้อความประกอบได้หลายบรรทัด; Dashboard activity อยู่นอกขอบเขตตาราง.
- ตรวจ class และ `git diff --check` ผ่าน. ไม่ได้ตรวจภาพใน Browser หรือรันชุดทดสอบ.

## ⚠️ ต้องทดสอบโดยคุณ

เปิด `/customers`, `/products` และ `/users` บน Desktop/มือถือ เลือกรายการที่ชื่อหรือข้อมูลยาว: ข้อความควรแสดงครบโดยขึ้นบรรทัดใหม่ ไม่มี `...`; แถวสูงขึ้นตามข้อความ และค้นหา/กรอง/แบ่งหน้าได้เหมือนเดิม.
