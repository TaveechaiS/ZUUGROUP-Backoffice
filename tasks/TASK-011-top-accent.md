## ขอบเขตและแผนย่อย

1. บันทึกข้อกำหนดและแผนสั้นสำหรับแถบสีด้านบน
2. เพิ่มขอบบนของ `.workspace` สี `#1A58A7` สูงประมาณ 10px ให้ต่อกับ Topbar ตามภาพ
3. ตรวจภาพหน้า Desktop ทั้ง Sidebar ขยายและย่อ และตรวจ CSS ที่แก้
4. ตามผลตรวจของเจ้าของโครงการ: ทำให้สีน้ำเงินอยู่หลังมุมโค้งซ้ายบนของ Topbar และให้พื้นที่เนื้อหายังคงสีขาว แล้วตรวจภาพซ้ำ

## ผลที่ทำและตรวจแล้ว

- เพิ่มขอบบน `10px solid var(--blue-700)` ที่ `.workspace` ใน `src/app/globals.css`
- ดูหน้า `/customers/dashboard` บน Desktop ทั้ง Sidebar ขยายและย่อแล้ว เห็นแถบสีน้ำเงินเหนือ Topbar ตลอดพื้นที่เนื้อหา
- เจ้าของโครงการตรวจแล้วพบว่ามุมขอบยังไม่มน จึงเปลี่ยน `.workspace` ให้เป็นพื้นสีน้ำเงินหลังมุมโค้ง `25px` ของ Topbar และกำหนด `.page-content` ให้คงสีขาว
- ตรวจภาพ Desktop ซ้ำทั้ง Sidebar ขยายและย่อแล้ว เห็นมุมโค้งซ้ายบนกับพื้นสีน้ำเงินด้านหลังตามภาพตัวอย่าง
- งานนี้แก้เฉพาะ CSS; ไม่มีการเพิ่มการทดสอบอัตโนมัติ

## ⚠️ ต้องทดสอบโดยคุณ

- เปิดหน้าเว็บบน Desktop: ต้องเห็นแถบสีน้ำเงินแนวนอนเหนือ Topbar ในพื้นที่เนื้อหา
- กดย่อ/ขยาย Sidebar: แถบสีต้องต่อเนื่องเหนือพื้นที่เนื้อหาในทั้งสองสถานะ
