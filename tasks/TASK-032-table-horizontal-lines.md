# TASK-032 — ลบเส้นแนวตั้งของตาราง

- **สถานะ:** READY_FOR_USER_TEST
- **ผู้รับผิดชอบ:** AI
- **Branch:** AI
- **Specs:** Project Specs §22.11
**Plan:** [แผนย่อย](../docs/plans/2026-09-25-table-horizontal-lines-plan.md)

## ขอบเขต

ลบเส้นคั่นคอลัมน์ของตารางรายการที่ใช้ร่วมกันและตารางผู้ใช้งาน; เพิ่มเส้นกรอบนอกครบสี่ด้านตามคำแก้ล่าสุด. คงเส้นคั่นแถว สี และการทำงานเดิม.

## ผลดำเนินการ

- เอา `border-r` ออกจากหัวคอลัมน์และเซลล์ทั้งสอง component. ตามคำแก้ล่าสุดเพิ่ม `border` รอบ wrapper ทั้งสี่ด้าน.
- ยังคงเส้นคั่นแถว `border-t` และเส้นเหนือ Pagination; ตรวจ class/diff ผ่าน. ไม่ได้เปิดตรวจภาพใน Browser หลังแก้รอบนี้.

## ⚠️ ต้องทดสอบโดยคุณ

เปิด `/customers`, `/products` และ `/users`: เห็นเส้นกรอบรอบตารางครบสี่ด้าน แต่ไม่มีเส้นคั่นแนวตั้ง; ยังมีเส้นคั่นแถวและเส้นเหนือ Pagination และค้นหา/กรอง/แบ่งหน้าได้เหมือนเดิม.
