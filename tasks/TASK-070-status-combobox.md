# TASK-070 — เลือกสถานะด้วย Combobox

สถานะ: READY_FOR_USER_TEST — เจ้าของขอ 2026-10-02

## Specs

ช่อง status ใน shared record form เพิ่ม/แก้ไข ใช้ combobox พิมพ์ค้นหาและเลือกสถานะ ห้ามบันทึกคำค้นอิสระ ใช้สถานะที่มีจริงจาก /api/{module}/filters รวมค่าปัจจุบันและค่าเริ่มต้น “ใช้งานอยู่” เดิม คงค่าเดิมจนเลือกรายการใหม่ ไม่กำหนด enum หรือ transition ใหม่

## แผนย่อย

1. ตรวจ field status และ filters API เดิม บันทึกเอกสาร
2. ใช้ RelationPicker combobox เดิมกับ status โดยแปลง statuses เป็นตัวเลือก ไม่มี pagination สำหรับชุด statuses ที่ API คืนครบ
3. ข้อความ required เป็น “กรุณาเลือกสถานะ” รักษา * สีแดง คีย์บอร์ด/เมาส์/ยกเลิกและค่าปัจจุบัน ตรวจ lint/type-check/diff

ไฟล์: src/components/pages/record-form-page.tsx, Specs/Plan/ACTIVE และ Task นี้ ไม่เปลี่ยน DB/API/กฎสถานะ

ผล: status ใช้ combobox เดิมแล้ว ดึง statuses จาก filters API หนึ่งครั้งและค้นหาฝั่งหน้าเว็บ รวมค่าปัจจุบัน/ค่าเริ่มต้นเดิม ปิดโดยไม่เลือกคงค่าเดิม เลือกเท่านั้นจึงเปลี่ยนค่า ไม่มี pagination สำหรับ status และ required แจ้งกรุณาเลือกสถานะสีแดง type-check/eslint/diff-check ผ่าน ไม่ทดสอบ API/หน้าจอจริงอัตโนมัติ

## ⚠️ ต้องทดสอบโดยคุณ

เปิดเพิ่ม/แก้ไขรายโมดูล กดสถานะ ต้องเห็น dropdown ค้นหาและเลือกได้ด้วยเมาส์/ArrowDown/Enter พิมพ์คำที่ไม่มีแล้วปิดต้องคงสถานะเดิม เลือกยังไม่ระบุแล้วบันทึกต้องแสดงกรุณาเลือกสถานะสีแดง บันทึกค่าที่เลือกแล้วเปิดดูอีกครั้งต้องตรงกัน
