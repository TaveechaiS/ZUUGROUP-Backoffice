# TASK-057 — เปิดรายละเอียดจากทั้งแถวตาราง

สถานะ: READY_FOR_USER_TEST

เจ้าของโครงการขอ 2026-10-01 ให้กดแถวข้อมูลตรงไหนก็ได้เพื่อดูรายละเอียด แทนชื่อหรือคอลัมน์ท้าย.

ขอบเขตและลำดับตาม [Specs](../docs/specs/2026-10-01-clickable-table-rows.md) และ [Plan](../docs/plans/2026-10-01-clickable-table-rows-plan.md).

ผลดำเนินการ: รายการโมดูล, สินค้า และผู้ใช้งานเปิด URL รายละเอียดเดิมจากทั้งแถวด้วยเมาส์หรือ Enter/Space; แถวมือถือของรายการโมดูลรองรับเช่นเดียวกัน. ถอดลิงก์เฉพาะชื่อและคอลัมน์ “จัดการ” ของผู้ใช้งาน. แถวโมดูลที่ลบแล้วและ Audit Logs ไม่มีหน้ารายละเอียด จึงคงพฤติกรรมเดิม.

ผลตรวจ: `npm run lint`, `npm run type-check`, `npm run build`, `git diff --check` ผ่าน. รอเจ้าของทดสอบบนหน้าจอจริง.
