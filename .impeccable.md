# Design Context

## Product and audience
ZUUGROUP is a Thai-language B2B back-office for a pharmaceutical and medical-supplies distributor. The primary audience for this foundation is the Admin user, who manages CRUD work across the modules, subject to the approved business rules and permissions in the Project Specs.

## Main jobs
Admins manage customers, products and stock, purchasing, sales and delivery, finance, and system data. The Dashboard is only a placeholder for now; do not add KPIs or aggregate widgets until the data modules exist. The Dashboard can be completed after those modules.

## Brand and visual direction
Use the user's existing Figma file `Zuugroup`, especially its `Dektop` and `Components` pages, and match the practical back-office visual language shown there. The user supplied the primary blue palette; do not invent a replacement palette or change the Figma file.

Keep the interface in Thai, with Asia/Bangkok time conventions and Buddhist Era dates where dates appear. Reuse the existing Figma components and assets when visible and available. Preserve the existing role list; never add Inventory.

## Scope constraints
This Design foundation may implement shared layout, colors, typography and navigation presentation. It must not implement business CRUD behavior, authentication/authorization logic, database schema, or dashboard metrics. Do not guess any rule marked OPEN in the Project Specs.
