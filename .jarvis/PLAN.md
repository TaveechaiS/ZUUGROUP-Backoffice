## ค่าแนะนำ (ต้องอนุมัติ เพราะเป็นข้อ OPEN)

E1 ค่าใช้จ่าย: EX-ปีพ.ศ.-0001, วันที่, หมวด (ตั้งค่าได้ในข้อมูลพื้นฐาน), รายละเอียด, จำนวนเงินรวม VAT, ผู้รับเงิน (ข้อความ), ไฟล์แนบ, สถานะ บันทึกแล้ว/ยกเลิก(เหตุผล). Admin/CFO บันทึก ไม่มีขั้นอนุมัติ
B1 วางบิล: ใบแจ้งหนี้ INV-ปีพ.ศ.-0001 สร้างจากคำสั่งซื้อเสร็จสิ้น 1 SO = 1 ใบ ยอดเท่ากับ SO; ครบกำหนด = วันที่ออก + เครดิตเทอมของลูกค้า
B2 รับชำระ: บันทึกรับเงินได้หลายครั้ง (วันที่/จำนวน/วิธี เงินสด|โอน|เช็ค/หมายเหตุ) ห้ามเกินยอดค้าง; สถานะ ค้างชำระ/ชำระบางส่วน/ชำระครบ/เกินกำหนด(คำนวณ)/ยกเลิก. แผนผ่อนรายเดือน (TASK-103) ยังไม่ทำ
B3 กลับเมนู "วางบิล & ลูกหนี้" ใน Side หลัก (เจ้าของซ่อนไว้ TASK-103)
F1 รายงานการเงิน: ลูกหนี้คงค้างตามอายุหนี้ (ยังไม่ถึงกำหนด/1–30/31–60/61–90/>90 วัน ณ วันนี้), รับชำระตามช่วงวันที่, ค่าใช้จ่ายตามหมวด/ช่วงวันที่. ไม่ทำกำไรขาดทุน
P1 ผูกโปรโมชัน: Sales/Admin เลือกโปรโมชัน "ใช้งาน" ได้ในใบเสนอราคา/คำสั่งซื้อ; ระบบตรวจขั้นต่ำจากสินค้าที่ร่วมในเอกสาร; ของแถมเพิ่มเป็นบรรทัด ของแถม ราคา 0 แก้ไม่ได้ (จำนวนตามโปร ×1 ไม่คูณตามจำนวนเท่า); ส่วนลดบาท/% หักท้ายบิล (เพิ่มคอลัมน์ส่วนลดท้ายบิล); เก็บสำเนาเงื่อนไขโปรในเอกสาร; ใช้ได้ 1 โปรต่อเอกสาร
P2 ของแถมจอง/ตัดจากคลังที่โปรกำหนด (MARKETING ค่าเริ่มต้น) FEFO; ของไม่พอเลือกโปรไม่ได้. sales_order_lines/quotation_lines เปลี่ยน unique(order,product) เป็น unique(order,product,is_gift)
C1 ติดตามลูกค้า (/customers/dashboard): บันทึกการติดตาม FU-ปีพ.ศ.-0001 ลูกค้า/วันที่ติดต่อ/ช่องทาง โทร|เข้าพบ|LINE|อีเมล/สรุป/นัดครั้งถัดไป/สถานะ รอติดตาม|เสร็จแล้ว|ยกเลิก; รายการแท็บ ครบนัดวันนี้/เกินนัด
C2 เอกสารลูกค้า (/customers/documents): หน้ารวมไฟล์เอกสารจากข้อมูลลูกค้า (customer_files) อ่านอย่างเดียว กรองประเภท/ลูกค้า ไม่สร้างตารางใหม่
C3 คำขอเพิ่มลูกค้า (TASK-272): Sales/Manager ส่งคำขอด้วยฟอร์มเดียวกับเพิ่มลูกค้า → Admin อนุมัติ (สร้างลูกค้าทันที) / ส่งกลับแก้ (เหตุผล) / ไม่อนุมัติ (เหตุผล); "คำขอของฉัน" สำหรับผู้ส่ง. ไม่มีแจ้งเตือนภายนอก
S1 ตรวจนับ: รอบตรวจนับ SC-ปีพ.ศ.-0001 เลือกคลัง → ระบบดึงรายการล็อตคงเหลือ ณ ตอนสร้าง (ยอดระบบ) → Admin คีย์จำนวนนับจริง → แสดงส่วนต่าง; ปิดรอบแล้วแก้ไม่ได้; ไม่ปรับยอด/ไม่สร้าง Ledger (กฎเดิม OPEN-15)
R1 สิทธิ์ตาม Role (ทำหลังทุกหน้า): Sales เห็นลูกค้า/เอกสาร/ยอดขายเฉพาะลูกค้าในเขตตน; Manager เห็นทั้งบริษัท (OPEN-01 เลือกค่าง่ายสุด); ต้นทุนเฉพาะ Admin/CFO; บัญชี (CFO) เห็นการเงินทั้งหมด; Admin ทุกอย่าง
X1 ส่งออก: ปุ่ม CSV (UTF-8 BOM เปิดใน Excel ได้) ในทุกหน้ารายงาน ใช้เงื่อนไขเดียวกับหน้าจอ
X2 PDF: ใบเสนอราคา / ใบแจ้งหนี้ / ใบสั่งซื้อ ผ่านหน้าพิมพ์ของเบราว์เซอร์ (print CSS) ไม่เพิ่ม dependency; ของแถมไม่พิมพ์ราคา
