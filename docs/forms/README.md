# แบบฟอร์มกรอกข้อกำหนด

เปิด business-requirements.html ด้วย Chrome/Edge แล้วเลือกโมดูลเพื่อกรอก. ไฟล์นี้ไม่ต้องติดตั้งหรือเปิดเซิร์ฟเวอร์ ไม่ส่งข้อมูลขึ้นเว็บ.

รองรับ 22 โมดูล/หัวข้อ รวม 14 โมดูลข้อมูลกลางพร้อม 113 ฟิลด์ปัจจุบัน. กรอกเฉพาะสิ่งที่รู้ เว้นข้อที่ยังไม่สรุปได้. ช่องสิทธิ์แยก Admin/Manager/Sales/CFO.

ฟอร์มใหม่กรอกทีละจุด:

ทุกช่องมีคำอธิบายภาษาไทยและตัวอย่างสำหรับคนไม่ใช่สายเทคนิค. “ใช้ช่องข้อมูลนี้” ถามว่าต้องการมีช่องนี้หรือไม่ ส่วน “บังคับกรอก” ถามว่าต้องกรอกก่อนบันทึกหรือไม่. อ่านคำอธิบายใต้ช่องก่อนเลือก; ตัวอย่างไม่ได้กำหนดคำตอบแทนคุณ.

- ตัวอย่างข้อมูลหนึ่งช่องต่อหนึ่งฟิลด์; เปิด “เลือกข้อกำหนด” เพื่อเลือกใช้งาน/บังคับ/ห้ามซ้ำ/ค้นหา/ตัวกรอง/ห้ามแก้
- สถานะหนึ่งช่องต่อหนึ่งชื่อ กดเพิ่มสถานะได้สูงสุด 20 แถว
- ขั้นตอนแยกจากสถานะ/ไปสถานะ/ผู้เปลี่ยน/ผู้อนุมัติ/เงื่อนไข กดเพิ่มได้สูงสุด 20 ขั้นตอน
- สิทธิ์แต่ละ Role เลือกอนุญาต/ไม่อนุญาต/ยังไม่สรุปทีละคำสั่ง พร้อมขอบเขตข้อมูล
- รายละเอียดแบบยาวไม่บังคับ; คำตอบจากฟอร์มเดิมอยู่ในหัวข้อพับ “รายละเอียดเพิ่มเติม / คำตอบจากฟอร์มเดิม”

ค่า “ยังไม่สรุป” ไม่ใช่การให้สิทธิ์หรือปฏิเสธสิทธิ์. การเลือกในฟอร์มนี้ไม่แก้ระบบจริง. รองรับร่างและ JSON รุ่นเดิมโดยรักษาคำตอบเก่า.

- บันทึกร่าง: เก็บในเบราว์เซอร์และเครื่องนี้ อาจไม่ทำงานในบางโหมด/private หรือเมื่อเปิดจาก file URL; หากแจ้งบันทึกไม่ได้ให้ส่งออก
- ส่งออกคำตอบ: ได้ JSON รวมทุกโมดูลที่กรอก นำไฟล์นี้ส่งกลับให้ผู้ทำงานหรือเก็บสำรอง
- นำเข้าร่าง: เลือก JSON ที่เคยส่งออก จะมีคำถามก่อนแทนร่างที่มีคำตอบ; ส่งออกเก็บก่อนหากต้องการรักษาร่างเดิม
- พิมพ์/บันทึก PDF: รวมคำตอบทุกโมดูลที่กรอก ใช้ Save as PDF ในหน้าต่างพิมพ์

การล้างข้อมูลเบราว์เซอร์อาจทำให้ร่างหาย; ส่งออกไฟล์ก่อนปิดหรือย้ายเครื่อง. ไม่ใส่รหัสผ่าน/secret key ในคำตอบ.

Google Forms ยังไม่ได้สร้าง เพราะเบราว์เซอร์ที่เชื่อมต่อยังต้อง login. HTML เป็นแบบฟอร์มที่ใช้ได้ทันที; หากต้องการ Google Forms โดยเฉพาะ ให้เข้าสู่ระบบในแท็บ Forms ก่อนแล้วแจ้งให้ทำต่อ.

## ⚠️ ต้องทดสอบโดยคุณ

กรอกชื่อ/ตัวอย่างในหนึ่งโมดูล เปลี่ยนไปอีกโมดูลแล้วกลับ คำตอบควรอยู่. ส่งออก JSON แล้วนำกลับเข้า คำตอบควรเหมือนเดิม. พิมพ์ควรรวมทุกโมดูลที่กรอก. แบบฟอร์มนี้ยังอยู่ในชุดรอ commit รวมหลังตรวจรับ.
