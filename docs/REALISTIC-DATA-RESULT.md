## Snapshot และย้อนกลับ

เก็บโฟลเดอร์นี้ไว้ หากต้องย้อนกลับเฉพาะค่าที่ Task นี้เปลี่ยน ใช้:

```powershell

```

ตัว runner ตรวจ project จาก DATABASE_URL และตรวจค่าปัจจุบันตรง after ก่อนย้อนกลับ หากมีใครแก้ค่าที่เกี่ยวข้องภายหลังจะหยุดและ rollback ทั้ง transaction ไม่เขียนทับการแก้ใหม่ การลบเชิงตรรกะยังคงเดิม

เตรียมแผน/SQL ซ้ำจาก snapshot เดิม: node scripts/realistic-refresh-plan.mjs --emit; ตรวจแบบไม่บันทึก: node scripts/run-realistic-refresh.mjs --dry-run ไม่มีการย้าย snapshot ข้ามเครื่องอัตโนมัติ
