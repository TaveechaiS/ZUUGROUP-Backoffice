# TASK-082 — แถบสีและ Header ติดด้านบน

สถานะ: APPROVED จากคำขอเจ้าของ 2026-10-03

คำยืนยันล่าสุด: เจ้าของให้เอาการล็อก Header ตอนเลื่อนออก. Header และแถบสีน้ำเงินสูง 10px อยู่ใน flow ปกติและเลื่อนพ้นหน้าจอพร้อมเนื้อหา. คงชื่อหน้า วันที่ บัญชีผู้ใช้และปุ่มออกจากระบบ. คงสีและมุมซ้ายบนโค้ง 25px บน desktop. เมื่อย่อหรือขยาย Sidebar ให้ขยับตามความกว้างพื้นที่เนื้อหา.

ทั้ง desktop/mobile ให้ Header และแถบสีเลื่อนตามหน้า. ใช้ Tailwind utility ใน component ตามกติกา UI.

ตรวจรับ: เลื่อนหน้าที่ยาวบน desktop/mobile แล้ว Header และแถบสีต้องเลื่อนพ้นจอ. กลับต้นหน้าต้องเห็นและใช้ปุ่มได้; ทดสอบย่อ/ขยาย Sidebar.
