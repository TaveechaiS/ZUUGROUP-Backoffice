# TASK-065 — ป้ายสถานะตามภาพของเจ้าของ

สถานะอนุมัติ 2026-10-02. เจ้าของยืนยันครอบคลุมทุกสถานะ รวมร่าง/ระงับ/มี/ไม่มี และให้เลือกสีได้โดยใช้ bgระดับ50/textระดับ600. ใช้รูปแบบพื้นสีอ่อน/มุมมน/จุดกลมหน้า label/น้ำหนักตัวอักษร semibold ตามภาพ. UI ไทย และ Tailwind inline.

ขอบเขต component StatusBadge กลาง: shared ModuleListPage/ActivityRow และ users/products list/detail. คงข้อความสถานะจริงแต่จัดรูปแบบเดียวกัน. ไม่เปลี่ยนข้อมูล/endpoint/คำนวณยอดสต็อก หรือแปลงสถานะใช้งานเป็นสถานะปริมาณคลัง.

เพิ่ม shared RecordDetailPage ช่องstatus และ Dashboard เอกสารล่าสุด. สี emerald50/600 ปกติ/มี/ใช้งาน/สำเร็จ, orange50/600 รอ/เตือน/ต่ำกว่าปกติ, red50/600 ระงับ/ลบ/ไม่ใช้งาน/ผิดปกติ, blue50/600 กำลังดำเนินการ/ยังไม่ครบกำหนด, slate50/600 ร่าง/ไม่มี/สิ้นสุด/ยังไม่ระบุ/ข้อความไม่รู้จัก. จุดใช้currentColorจึงตรงtext600. “มี/ไม่มี” ใช้สีกำกับการมีข้อมูล ไม่ตีความไม่มีเป็นerror. ค่าที่ไม่รู้จักยังได้badgeเทาและlabelเดิม ไม่เดากฎเพิ่มเติม.

สี: success เขียว (ปกติ/ใช้งาน/สำเร็จ/อนุมัติ), warning ส้ม (ต่ำกว่าปกติ/รอ/ติดตาม), danger แดง (ต่ำผิดปกติ/ลบแล้ว/ระงับ/ไม่ใช้งาน/ผิดพลาด), neutral เทา (ร่าง/ยังไม่ระบุ). ตรวจ negative ก่อน positive โดยใช้ mapping ชัดเจน; ห้าม regex “ปกติ” จับผิดว่า “ต่ำผิดปกติ” เป็นเขียว. จุดตกแต่ง aria-hidden และข้อความยังสื่อความหมายโดยไม่ต้องดูสี. ไม่เพิ่มสถานะใหม่ใน DB เพื่อแสดงตัวอย่าง.

เป้ารูปแบบ: dot ประมาณ8px, gap8px, text-sm/semibold, pill px3/py1.5; ข้อความยาวรองรับwrapในตาราง, dotไม่หด. สีพื้น/ตัวอักษร/จุดใกล้ภาพ และตรวจ contrast ให้ข้อความอ่านได้. หน้า detail/list ใช้ component เดียวกัน.

ข้อกำหนดถาวรจากเจ้าของ: ทุกหน้าปัจจุบันและทุกสถานะที่จะสร้างต่อไปใช้ StatusBadge เมื่อแสดงป้ายสถานะ. เพิ่มmappingสีที่componentกลาง;ห้ามแยกpill/styleใหม่แต่ละหน้า. รวมสถานะ ModulePlaceholder “เตรียมโครงหน้าแล้ว” ใช้info blue50/600. คำอธิบายทั่วไป/ปุ่มaction/ช่องselectสำหรับเลือกสถานะยังเป็น controls/textเดิม. บันทึกมาตรฐานใน AGENTS.md ข้อ14 และ docs/STATUS-BADGE-GUIDE.md.

หัวคอลัมน์ที่แสดงสถานะต้องใช้คำว่า “สถานะ” และ scope=col; มุมมองmobileของsharedlistมีlabelสถานะกับbadge. แก้ RecordTableRow desktopที่ตกหล่นให้ใช้StatusBadgeเหมือนmobile; deletedรายการโมดูลใช้ป้ายลบแล้ว. ไม่เพิ่มstatusfieldปลอมในAuditที่แสดงaction.
