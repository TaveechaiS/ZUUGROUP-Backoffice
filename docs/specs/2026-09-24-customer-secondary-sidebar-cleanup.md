# ข้อกำหนดสั้น — Sidebar ย่อยลูกค้า

**ที่มา:** คำขอเจ้าของโครงการ 2026-09-24

**Task:** TASK-020

- เอาหัวข้อ “ลูกค้า”, คำอธิบาย “เมนูย่อย” และช่องค้นหาออกจาก Sidebar ย่อยของหน้าลูกค้า.
- คงลิงก์/ชื่อหน้าสำหรับการนำทางลูกค้าไว้ครบ.
- คงความกว้าง Sidebar ย่อย 250px บน Desktop และ layout สำหรับจอแคบเดิม.
- Container ของ Sidebar ย่อยไม่มี padding แนวนอน และใช้ padding แนวตั้ง `py-2` ทุก breakpoint; คง padding ภายในลิงก์เพื่อให้กดใช้งานได้สะดวก.
- ไม่เปลี่ยน Sidebar หลัก, routes, หรือเนื้อหาของหน้าปลายทาง.
