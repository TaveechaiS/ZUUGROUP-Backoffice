# TASK-056: คอมโพเนนต์สถานะกลาง

เจ้าของโครงการขอคอมโพเนนต์ `SuccessAlertComponent`, `NotFoundComponent`, `LoadingComponent` ตามตัวอย่างที่ให้มา และให้เก็บ SVG ที่ใช้ซ้ำไว้ใต้ `src/components/icons/`.

- SuccessAlert เป็น dialog แจ้งผลสำเร็จ ควบคุมด้วย `isOpen` มีหัวข้อ คำอธิบาย ปุ่มปิด และตั้งเวลาปิดอัตโนมัติได้ โดยล้าง timer เมื่อปิดหรือ unmount.
- NotFound ใช้กับผลลัพธ์ว่างหรือค้นหาไม่พบ มีข้อความไทยและการกระทำลองใหม่/ย้อนกลับที่หน้าเรียกกำหนดได้ ไม่ใช่หน้า HTTP 404.
- Loading แสดงสถานะกำลังโหลดพร้อม `role="status"`; ซ่อนเมื่อ `isVisible` เป็น false.
- SVG ของสถานะสำเร็จ สถานะว่าง ปิด และค้นหาเป็น React icon ที่ `src/components/icons/`; style ใช้ Tailwind utility ใน `className` และ UI ใช้ภาษาไทย.
- ใช้คอมโพเนนต์ในหน้ารายการโมดูล (โหลด ว่าง กู้คืนสำเร็จ), รายละเอียดสินค้า (บันทึก/ลบ/กู้คืนสำเร็จ) และ Dashboard (โหลด). คง error และ API flow เดิม.
- ไม่มีการเปลี่ยนฐานข้อมูล, API route, สิทธิ์ หรือกฎธุรกิจที่อยู่ใน OPEN.

ตรวจรับ: lint/type-check/build ผ่าน; หน้าโหลดแสดงสถานะไทย, รายการว่างแสดงคำแนะนำและปุ่ม, การกระทำสำเร็จเปิด dialog ที่ปิดได้; dialog ไม่ปรากฏเมื่อยังไม่มีผลสำเร็จ.
