# TASK-057: เปิดรายละเอียดจากทั้งแถวตาราง

เจ้าของขอให้กดตำแหน่งใดก็ได้ของแถวข้อมูลเพื่อเปิดหน้ารายละเอียด แทนการต้องกดชื่อข้อมูลหรือปุ่มคอลัมน์สุดท้าย.

- ใช้กับแถวที่มีหน้ารายละเอียดในรายการโมดูล, สินค้า และผู้ใช้งาน รวมถึงแถวรูปแบบมือถือของรายการโมดูล.
- แถวต้องแสดง affordance ว่ากดได้, รองรับ Enter/Space เมื่อโฟกัสด้วยคีย์บอร์ด และใช้ URL รายละเอียดเดิม.
- แถวที่ไม่มีหน้ารายละเอียด เช่น รายการที่ลบแล้วในโมดูล และ Audit Logs ไม่เปลี่ยนเป็นลิงก์. ปุ่มกู้คืนและปุ่มอื่นยังทำงานเฉพาะของตน.
- ไม่เปลี่ยน API, DB, สิทธิ์หรือข้อมูล.

ตรวจรับ: กดเซลล์ใดก็ได้ของแถวที่เปิดรายละเอียดได้; กด Enter/Space บนแถวได้; ปุ่มกู้คืนและส่วนกรอง/แบ่งหน้าไม่เปิดรายละเอียดโดยไม่ตั้งใจ.
