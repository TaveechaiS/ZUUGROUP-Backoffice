# ข้อกำหนด — ใช้คลาสขนาดของ Tailwind ใน Sidebar และ Topbar

**ที่มา:** คำขอเจ้าของโครงการ 2026-09-24

**Task:** TASK-022

- ตรวจคลาสกำหนดขนาดใน `Sidebar` และ `Topbar` แล้วใช้ utility ของ Tailwind แทนค่า pixel แบบกำหนดเองเมื่อได้ขนาดเท่ากัน.
- ข้อความ 14px ใช้ `text-sm`; ข้อความ 16px ใช้ `text-base` เมื่อพบ. ขนาดตัวอักษรที่ไม่มีค่าเทียบตรงตัวปรับขึ้นตาม TASK-023.
- ระยะห่างและมิติที่เป็นจำนวนพิกเซลคู่และอยู่ในสเกล `--spacing: 0.25rem` ใช้ utility ตัวเลขของ Tailwind เช่น `px-[10px]` เป็น `px-2.5`.
- ค่าขนาดอื่นที่ไม่มี utility เทียบตรงตัว, ค่าภาพตกแต่งเฉพาะจุด, สี, เส้นขอบ, design token และค่าตัวแปร CSS คงเดิม.
- ขนาดตัวอักษร ระยะห่าง มิติอื่น และ breakpoint คงเดิม; ใช้ความสูงบรรทัดตามค่าเริ่มต้นของคลาสตัวอักษร Tailwind.
