# TASK-090 ชุดงานเตรียมก่อนข้อมูลจริง

เจ้าของสั่งทำงานเตรียมทั้งหมดที่เสนอให้เสร็จ ส่งทดสอบครั้งเดียวและ commit ครั้งเดียวหลังตรวจรับ. TASK-089 ตรวจผ่านแล้ว ไม่ checkpoint แยกรอบนี้.

ส่งแบบฟอร์มข้อกำหนดครบ 14 shared record modules พร้อมสินค้า/ผู้ใช้/คลัง/รายงาน/Dashboard/Audit. แสดงฟิลด์ปัจจุบันจาก registry และจุดที่รอเจ้าของเติมแยกกัน. ช่องสิทธิ์ใช้ Admin/Manager/Sales/CFO เท่านั้น. กฎ OPEN ไม่ปิดเอง; Dashboard API/Deploy ที่พักไว้ยังไม่เริ่ม.

คู่มือภาษาไทยตามหน้าจอจริง: รายการ/ค้นหา/แบ่งหน้า/คลิกแถว/ฟอร์ม/ยืนยันยกเลิก/SuccessAlert/ลบกู้คืน/ข้อผิดพลาด/รายงาน. ไม่อ้างว่าคลังมีหน้าจอ CRUD หรือรายงานมียอดจริงที่ยังไม่คำนวณ.

รายการตรวจรับเดียวรวมคำสั่ง tests ที่ผ่านแล้ว + ตรวจเอกสาร + flow UI ที่ยังต้องดู โดยใช้รายการทดสอบใหม่และลบเพื่อซ่อนหลังเสร็จ. ห้ามใช้ชุดนี้สั่งแก้/ลบข้อมูลจริงหรืออนุมัติธุรกิจแทนเจ้าของ. หลังเจ้าของตรวจรับให้ commit TASK-089/090 พร้อมกันบน AI ครั้งเดียว.
