# ข้อกำหนดสั้น — ลำดับชั้นหน้าจอ

**ที่มา:** คำอธิบายเจ้าของโครงการ 2026-09-24

**Task:** TASK-015

1. **Sidebar หลัก** อยู่ด้านนอกของพื้นที่เนื้อหา แสดงกลุ่มและโมดูลหลัก. “จัดการข้อมูล” เป็นชื่อกลุ่มที่ครอบ ลูกค้า, สินค้าและสต็อก และจัดซื้อ & รับเข้าสต็อก; ไม่ใช่หน้าที่เปิดเอง.
2. **Top bar** ติดกับส่วนบนของพื้นที่ body ของโมดูลที่เลือก.
3. **Sidebar ย่อยใน body** เป็นตัวนำทางของข้อมูลภายในโมดูล เปิดหน้าย่อย เช่น เมนูย่อยของลูกค้า.
4. **Tab** เป็นชั้นนำทางภายในหน้าย่อยอีกชั้นหนึ่ง. ต้องรู้รายการ tab ของหน้านั้นก่อนออกแบบหรือสร้าง.
5. **Filter** เป็นชั้นถัดจาก tab ตามคำอธิบายล่าสุด. รูปแบบว่าเป็นหน้าแยกหรือส่วนในหน้า tab ยังรอเจ้าของโครงการยืนยัน; ห้ามกำหนด route/พฤติกรรมเพิ่มเอง.

โครงความสัมพันธ์: `Sidebar หลัก → โมดูล → Top bar + Sidebar ย่อยใน body → หน้าย่อย → Tab → Filter → ข้อมูล`.

**สถานะโค้ดปัจจุบัน:** มี Sidebar หลักและ Top bar. หลัง TASK-016 Sidebar ย่อยของลูกค้าอยู่ใน body ใต้ Top bar และแสดงอิสระจากสถานะย่อ/ขยาย Sidebar หลัก. ยังไม่มี tab หรือ filter จริง และยังรอรายละเอียด sidebar ย่อยของโมดูลอื่น.
