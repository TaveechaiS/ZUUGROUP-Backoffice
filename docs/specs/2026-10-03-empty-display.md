# TASK-084 — แสดงเครื่องหมายเมื่อไม่มีข้อมูล

สถานะ: APPROVED จากคำขอเจ้าของ 2026-10-03 ให้เปลี่ยน `?? ''` เป็น `?? '-'`.

ข้อความข้อมูลที่แสดงใน UI ใช้ `-` เมื่อค่าเป็น null/undefined หรือข้อความว่าง. เปลี่ยน fallback ที่เป็นขีดยาว `—` ให้เป็นขีด `-` เช่นกัน เพื่อให้ใช้เครื่องหมายเดียวกันทั้งตาราง รายละเอียด และ component กลาง. ค่า 0 ต้องยังแสดง 0.

ค่าเริ่มต้นของช่องค้นหา ฟอร์ม รหัสสัมพันธ์และค่าที่ใช้ validation/API เป็นข้อมูลสำหรับประมวลผล จึงคง empty string ตามหน้าที่; ขีดเป็น placeholder สำหรับแสดงผลเท่านั้น.

ตรวจรับ: เปิดรายละเอียดที่เว้นข้อมูล optional และหน้ารายการที่ไม่มีทีม/เหตุผล ควรเห็น `-`; ค่า 0 ยังเห็น 0; ช่องค้นหา/ฟอร์มที่ยังไม่กรอกยังว่างและ validation ทำงานตามเดิม.
