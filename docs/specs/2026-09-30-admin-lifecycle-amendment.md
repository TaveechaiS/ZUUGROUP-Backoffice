# ข้อแก้ไข Specs — วงจรบัญชี Admin และการกู้คืน

**วันที่ยืนยัน:** 2026-09-30 (Asia/Bangkok)
**อ้างอิง:** SPEC-PROJECT-001 รุ่น 0.3, OPEN-14, G-04, TASK-036

## ข้อกำหนดที่เจ้าของโครงการอนุมัติ

- Admin จัดการบัญชีผู้ใช้และ Role จากหน้าเว็บ รวมถึงสร้างบัญชี Admin เพิ่มได้
- ระบบต้องป้องกันไม่ให้การปิดใช้งาน ลบ หรือเปลี่ยน Role ทำให้ไม่มี Admin ที่ยังเข้าใช้ระบบได้เหลืออยู่ การดำเนินการที่ทำให้เกิดสภาพดังกล่าวต้องถูกปฏิเสธ
- หาก Admin ทุกคนเข้าใช้ระบบไม่ได้ เจ้าของโครงการเป็นผู้กู้คืนจากภายนอกเว็บตาม [คู่มือกู้คืนบัญชี Admin](../runbooks/admin-account-recovery.md)
- นโยบายรหัสผ่านยังยึดตาม [ข้อแก้ไข 2026-09-30](2026-09-30-admin-managed-password-amendment.md): Admin ตั้งรหัสเริ่มต้นและรหัสใหม่เอง ไม่มีอีเมลหรือลิงก์เชิญ/รีเซ็ต
- หนึ่งบัญชีมีหนึ่ง Role ตามข้อยืนยันเดิม

รายละเอียดหน้าจอผู้ใช้งานเดิมที่ยังเขียนว่า “ส่งวิธีตั้ง/รีเซ็ตรหัสผ่าน” ให้ตีความตามข้อกำหนดข้างต้นเป็น Admin ตั้งรหัสให้โดยตรง ไม่มีการส่งอีเมลหรือลิงก์.

## ขอบเขต Gate

OPEN-14 ปิดและ G-04 ผ่านเมื่อ 2026-09-30. การทำระบบจริงยังต้องทำตาม runbook อย่างปลอดภัย: การใช้ Auth Admin API ต้องอยู่ฝั่งเซิร์ฟเวอร์ และขั้นตอนกู้คืน Admin ต้องทดสอบก่อนเปิดใช้ Auth จริง. G-10 เป็น Gate แยกและยังไม่ผ่าน.
