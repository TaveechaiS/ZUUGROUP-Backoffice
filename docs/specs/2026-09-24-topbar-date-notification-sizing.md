# ข้อกำหนด — ขนาดวันที่ การแจ้งเตือน และโปรไฟล์ผู้ใช้ใน Topbar

**ที่มา:** คำขอเจ้าของโครงการ 2026-09-24

**Task:** TASK-021

- ชื่อหน้าใน Topbar ใช้ `text-xl` 20px บน Desktop; จอแคบคง `text-lg` 18px.
- วันที่ใน Topbar ใช้ตัวอักษรขนาด 14px บน Desktop; จอแคบใช้ `text-xs` 12px ตาม TASK-023.
- ย่อปุ่มแจ้งเตือนจาก 40px เป็น 36px บน Desktop และจาก 28px เป็น 24px บนจอแคบ.
- ย่อไอคอนกระดิ่งจาก 20px เป็น 18px บน Desktop และจาก 16px เป็น 14px บนจอแคบ.
- วงกลมรูปโปรไฟล์ผู้ใช้มีขนาดเท่าปุ่มแจ้งเตือน: 36px บน Desktop และ 24px บนจอแคบ; คงชื่อและบทบาทเดิม.
- ขยายจุดแจ้งเตือนสีแดงบนไอคอนกระดิ่งจากรัศมี 3 เป็น 4 หน่วยใน SVG โดยคงตำแหน่งและสีเดิม.
- ใช้ SVG ลูกศรชี้ลงที่เจ้าของโครงการส่งมาแทนตัวอักษรลูกศรข้างโปรไฟล์: ขนาด 14×8, `viewBox="0 0 14 8"`, เส้น `#101828` หนา 2 ปลายและรอยต่อโค้ง.
- คงตำแหน่งส่วนอื่นและตัวแบ่งส่วนเดิม.
- ไม่เปลี่ยนความสูง Topbar หรือขนาดส่วนอื่น.
