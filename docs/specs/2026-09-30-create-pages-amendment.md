# ข้อแก้ไข Specs — หน้า Create ของโมดูลตัวอย่าง

**วันที่:** 2026-09-30 (Asia/Bangkok)
**สถานะ:** เจ้าของโครงการยืนยันให้แยกหน้าและย้ายฟอร์มเดิมก่อน
**อ้างอิง:** Project Specs รุ่น 0.3; TASK-038

หน้าที่ใช้ `ModuleListPage` และมีปุ่มเพิ่มรายการทั้งหมด 20 หน้า ต้องเปิดฟอร์มบน URL `<หน้ารายการ>/create` แทน drawer. หน้า `/users/create` ที่เชื่อมบัญชีจริงคงการทำงานของตน. หน้า Dashboard หลักซึ่งไม่มีปุ่มเพิ่มไม่อยู่ในขอบเขต.

หน้า Create ของโมดูลตัวอย่างใช้ฟอร์มเดิมที่กรอกชื่อรายการตัวอย่างหนึ่งช่อง มีปุ่มยกเลิก/กลับรายการ. เมื่อส่งฟอร์ม ให้กลับหน้ารายการและแสดงแถวตัวอย่างที่เพิ่มภายในแท็บเบราว์เซอร์นั้น โดยระบุชัดว่าเป็นข้อมูลตัวอย่าง ไม่บันทึกฐานข้อมูลจริง. ข้อมูลตัวอย่างนี้อยู่ได้จนปิดแท็บหรือ session ของแท็บสิ้นสุด; ไม่ถือเป็นข้อมูลธุรกิจจริง.

ทุกหน้า Create ต้องใช้ layout, ภาษาไทย, พ.ศ. และการตรวจ session เหมือนหน้ารายการ. ไม่เพิ่มฟอร์มกฎธุรกิจ/API/schema ของลูกค้า สินค้า เอกสาร การเงิน หรือโมดูลอื่นที่ยัง OPEN.
