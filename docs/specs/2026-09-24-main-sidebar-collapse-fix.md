# ข้อกำหนดสั้น — แก้การย่อ Sidebar หลัก

**ที่มา:** คำขอแก้บัคของเจ้าของโครงการ 2026-09-24 และ [ลำดับชั้นหน้าจอ](2026-09-24-navigation-hierarchy.md)

**Task:** TASK-016

- คลิกโลโก้แล้วย่อ Sidebar หลักจาก 326px เหลือแถบไอคอน 104px; คลิกอีกครั้งขยายกลับ. พื้นที่ Top bar/body ขยับตามความกว้างของ Sidebar หลักเท่านั้น.
- แถบย่อต้องแสดงไอคอนของทุกเมนูหลักที่ยืนยันแล้วตามลำดับเดิม (13 รายการ) พร้อมชื่อที่เข้าถึงได้และลิงก์เดิม; เมนูย่อยไม่ถูกรวมเป็นส่วนหนึ่งของ Sidebar หลัก.
- Sidebar ย่อยของลูกค้าอยู่ใน body ใต้ Top bar และแสดงตามโมดูลลูกค้า ไม่ขึ้นกับสถานะย่อ/ขยายของ Sidebar หลัก. ยังไม่สร้าง Sidebar ย่อยให้โมดูลอื่นหากไม่มีรายการที่ยืนยัน.
- บนจอแคบกว่า 1280px ให้เมนูย่อยของลูกค้าเป็นแถบนำทางแนวนอนเหนือเนื้อหา เพื่อคงพื้นที่อ่านข้อมูลและให้เข้าหน้าย่อยได้; จอกว้างใช้ Sidebar แนวตั้ง.
- คงเมนู สี โลโก้ ภาษาไทย และ placeholder routes เดิม. Tab/filter ยังไม่อยู่ในขอบเขตนี้.
