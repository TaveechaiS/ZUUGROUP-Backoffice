# ข้อกำหนดสั้น — ขนาดตัวอักษรเมนูหลัก Sidebar

**ที่มา:** คำขอเจ้าของโครงการ 2026-09-24

**Task:** TASK-018

1. ชื่อเมนูหลักใน Sidebar เช่น Dashboard, ลูกค้า, สินค้า, สต็อก และจัดซื้อ ใช้ Poppins Regular 400 ตาม TASK-017.
2. กำหนดขนาด Desktop เป็น 14px.
3. ขนาดบนจอแคบปรับจาก 11px เป็น 12px (`text-xs`) ตาม TASK-023; การตรวจและปรับ Responsive เพิ่มเติมเลื่อนไปหลังงานหลักตามที่เจ้าของโครงการระบุ.
4. ข้อกำหนดนี้เปลี่ยนเฉพาะชื่อเมนูหลัก ไม่เปลี่ยนหัวข้อกลุ่ม, โลโก้, เมนูย่อย, สี, ระยะห่าง, หรือพฤติกรรม Sidebar.

**ความสัมพันธ์:** ข้อนี้ระบุขนาดเมนูหลักเพิ่มเติมจากข้อกำหนดฟอนต์ใน TASK-017.
