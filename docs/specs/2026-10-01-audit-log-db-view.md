# ร่างข้อกำหนด — หน้า Audit Logs อ่านข้อมูล DB จริง

**สถานะ:** APPROVED — เจ้าของโครงการอนุมัติ TASK-045 วันที่ 2026-10-01
**อ้างอิง:** Project Specs §8.2, §20; แผนยกเลิก Mock 2026-10-01

## ขอบเขต

- `/audit-logs` แสดงเหตุการณ์จากตาราง `audit_events` ที่มีอยู่แล้ว เรียงเวลาล่าสุดก่อน พร้อม ID/เวลา/ผู้ทำ/Role/ชนิดเหตุการณ์/เลขอ้างอิงที่มีในข้อมูลจริง
- แสดงเวลา Asia/Bangkok และ พ.ศ.; แสดงผู้ทำว่า “ระบบ” เมื่อไม่มีผู้ใช้ผูกอยู่; ไม่สร้างชื่อบุคคล เลขเอกสาร หรือเหตุการณ์ที่ไม่มีใน DB
- เริ่มด้วยสิทธิ์ Admin เท่านั้นเพื่อไม่เปิดข้อมูลก่อน/หลังที่อาจมีข้อมูลจำกัดแก่ Role อื่น; สิทธิ์ละเอียดและการปิดฟิลด์ต้นทุนขยายเมื่อกำหนดใน Specs รายสิทธิ์
- ค้นหาและกรองเฉพาะฟิลด์ที่มีจริง; จำกัดจำนวนต่อหน้าและมีหน้าถัดไปเพื่อไม่ดึงประวัติทั้งหมดในครั้งเดียว
- หน้าอ่านอย่างเดียว ไม่มีคำสั่งเพิ่ม/แก้/ลบ; ปิด `/audit-logs/create` ที่ปัจจุบันเป็นฟอร์ม Mock
- รายละเอียดก่อน/หลังต้องไม่แสดงค่าที่อาจเป็น Secret; ในรอบแรกแสดงเฉพาะสรุป action/target/request ID และไม่เปิด JSON ดิบจนตรวจบัญชีฟิลด์แล้ว
- เมื่อไม่มีเหตุการณ์ให้แสดงสถานะว่าง ไม่ seed เหตุการณ์ปลอมเพื่อให้ตารางมีข้อมูล; ไม่มี migration ในรอบนี้
- ระยะเก็บและการส่งออกยังรอ OPEN-10; รอบนี้ไม่เพิ่มคำสั่ง export/archive/delete

## วิธีตรวจรับ

Admin เห็นเหตุการณ์ที่มีอยู่จริงจากการจัดการผู้ใช้และสินค้า; ผู้ไม่ใช่ Admin เข้าไม่ได้; ไม่มีแถว Mock หรือปุ่มเพิ่ม Audit; เวลาแสดง พ.ศ./Asia/Bangkok; หน้าไม่เผย JSON หรือ Secret
