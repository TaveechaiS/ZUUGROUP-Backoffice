# TASK-091 แบบฟอร์มกรอกข้อกำหนด

## ข้อแก้ไขจากเจ้าของ

เพิ่มเติม: เจ้าของจะส่งฟอร์มให้คนไม่ใช่สายเทคนิค ต้องมีคำอธิบายทุกช่องและตัวอย่างสั้น ๆ โดยเฉพาะ“ใช้ฟิลด์นี้”เทียบ“บังคับกรอก”, ค้นหาเทียบตัวกรอง, สิทธิ์/ขอบเขต/สถานะ/ภาษี/การปัดเศษ. ใช้“ช่องข้อมูล/ส่วนงาน”แทนศัพท์field/moduleในหน้าหลัก; แปลชื่อRoleที่แสดงแต่รักษาค่า/keysเดิม. ข้อความตัวอย่างไม่ใช่คำตอบที่อนุมัติ ไม่เติมตัวอย่างลงค่าinput และไม่แก้ร่างผู้ใช้.

ให้กรอกทีละจุดแทนพิมพ์อธิบายยาว: ตัวอย่างต่อfield พร้อมตัวเลือกใช้งาน/บังคับ/ค้นหา/filter/ห้ามซ้ำ/ห้ามแก้, inputสถานะและworkflowเพิ่มแถวได้, สิทธิ์selectดู/เพิ่ม/แก้/ลบ/กู้คืน/อนุมัติ/ส่งออกต่อ4Roleพร้อมขอบเขต. ไม่เลือกคำตอบธุรกิจแทนเจ้าของ. หมายเหตุเดิมเก็บพับได้ไม่หาย; schema JSONv1รองรับkeyใหม่และdraftเดิม. Print/exportรวมข้อมูลย่อยทั้งหมด.

เจ้าของขอให้ workbook เป็นแบบฟอร์มกรอกได้; Google Form เป็นทางเลือก ไม่บังคับ. Browser ที่เชื่อมต่อยังอยู่หน้า Google sign-in จึงส่ง standalone HTML ใช้ทันที. ไม่ถือว่าสร้าง Google Form แล้ว.

เลือกทุกโมดูลที่มีใน workbook, มี field reference จาก registry14/113 และโมดูลเฉพาะ. คำตอบไม่บังคับให้กรอกครบ; สถานะ/กฎ/สิทธิ์ไม่เลือกแทนเจ้าของ. บันทึกร่าง localStorage ของ browser (อาจใช้ไม่ได้ในบางโหมด), export/import JSON พร้อม version/schema validation, พิมพ์คำตอบทุกโมดูล. แจ้งเมื่อบันทึกไม่ได้และแนะนำ export. ไม่มี backend/network/secret/ฟอร์มใน public ของแอป.

เก็บ Google login เป็นขั้นที่เจ้าของทำเองหากเลือกภายหลัง. รวม TASK-091 กับ89/90ในการตรวจรับ/commitครั้งเดียว.
