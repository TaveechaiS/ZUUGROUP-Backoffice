# TASK-059: Loading เต็มหน้าจอ

เจ้าของโครงการขอให้สถานะ Loading ขึ้นกลางหน้าจอระหว่างเปลี่ยนหน้าและระหว่างโหลดข้อมูล พร้อมไอคอนและแอนิเมชันที่ลื่นตา.

- ใช้ `LoadingComponent` กลางเป็นพื้นผิวเต็ม viewport พร้อม icon ที่เก็บใน `src/components/icons/`; ข้อความไทยบอกว่ากำลังโหลดข้อมูล.
- เมื่อ Next.js เปลี่ยน route ที่ต้องรอเนื้อหา ให้ `src/app/loading.tsx` แสดง Loading ตาม file convention ของ Next.js 16.3.6.
- การอ่าน session ใน RootLayout เป็นงาน async ที่เกิดก่อน route fallback จึงครอบส่วนนี้ด้วย Suspense และ Loading เดียวกันเพื่อแสดงสถานะระหว่างเข้าเว็บครั้งแรก.
- เมื่อ Client Component โหลดข้อมูลหลัก ให้แสดง Loading เดียวกันใน Dashboard, รายการโมดูล และหน้ารายละเอียดโมดูล; ปิดเมื่อข้อมูลพร้อมหรือเกิดข้อผิดพลาด เพื่อให้เห็น error/action ตามเดิม.
- การโหลดข้อมูลย่อยในฟอร์มไม่ใช้ฉากเต็มหน้าจอ เพราะผู้ใช้ยังทำงานกับฟอร์มได้.
- ภาพ: พื้นขาวโปร่งบาง, วงแหวนสีน้ำเงินและไอคอนข้อมูล, ข้อความสั้น. Motion: วงแหวนหมุนช้าและไอคอน/จุดสถานะเปลี่ยนความเข้มอย่างนุ่มนวล; ปิด motion เมื่อระบบตั้งค่า reduced motion.
- ใช้ Tailwind utility ใน `className`; ไม่แก้ `globals.css`, API, DB หรือกฎธุรกิจ.

ตรวจรับ: เมื่อเข้าหน้า/เปลี่ยนหน้าที่โหลดช้าเห็นสถานะกลาง viewport; ขณะรอ GET หลักเห็น overlay; เมื่อข้อมูลสำเร็จ overlay หาย; เมื่อผิดพลาด overlay หายและเห็น error; reduced motion ไม่มีการหมุน/กะพริบ.

## งานติดตาม 2026-10-02 — Dashboard retry

เมื่อ Dashboard โหลดข้อมูลผิดพลาดและผู้ใช้กด “ลองใหม่” ให้ล้างข้อความผิดพลาดก่อนเริ่มคำขอใหม่ เพื่อแสดง Loading กลางหน้าจอระหว่างรอผล และกลับไปแสดงข้อผิดพลาดหากคำขอใหม่ล้มเหลวอีกครั้ง. ใช้ API และข้อความเดิม.

## งานติดตาม 2026-10-02 — Loading ในตารางรายการ

เจ้าของขอให้ระหว่างพิมพ์ค้นหา เปลี่ยนตัวกรอง/แท็บ หรือเปลี่ยนหน้ารายการ Loading อยู่ในกรอบตารางหรือส่วนแสดงข้อมูล เพื่อให้ช่องค้นหาและตัวกรองยังเห็นและใช้งานได้. ครอบคลุมหน้ารายการโมดูลทั่วไป สินค้า ผู้ใช้งาน และ Audit Logs. รูปแบบนี้แทนข้อกำหนด Loading เต็มจอสำหรับ Client GET ของหน้ารายการเท่านั้น; Loading ตอนเปลี่ยน route/อ่าน session, Dashboard และหน้ารายละเอียดคงตำแหน่งเดิม. เมื่อเกิด error ให้ Loading หายและแสดงข้อความพร้อมลองใหม่. ไม่แก้ผลการค้นหา API หรือ DB.

## งานติดตาม 2026-10-02 — โลโก้ Loading

เจ้าของส่งภาพโลโก้ Z สีน้ำเงินและระบุไฟล์ `public/Logoloading.png` ให้ใช้แทนสัญลักษณ์ Loading เดิมทั้งแบบเต็มจอและในกรอบตาราง. ใช้ไฟล์นี้ตรง ๆ โดยไม่สร้างหรือแก้ภาพ; ภาพมี alpha โปร่งใสอยู่แล้ว. ปรับขนาดแสดงผลให้ตัดพื้นที่ว่างรอบตัวโลโก้ในกรอบ component, คงข้อความและการเคลื่อนไหวที่รองรับ reduced motion. ไม่เปลี่ยน `public/logo.png` สีขาวที่ใช้ในส่วนอื่น.

## งานติดตาม 2026-10-03 — ขนาดโลโก้และวงแหวน

เจ้าของยืนยันโลโก้ใหม่แล้วและขอให้ลดส่วนที่มองเห็นให้ใกล้ไอคอนเดิม (เต็มจอประมาณ 56px, ในตารางประมาณ 32px) พร้อมคืนวงแหวนสองชั้นรอบโลโก้ในทั้งสองรูปแบบ. วงแหวนชั้นนอกหมุนอย่างนุ่มนวลเมื่ออนุญาต motion และหยุดเมื่อใช้ reduced motion. คงไฟล์โลโก้ ข้อความ และตำแหน่ง Loading เดิม.
