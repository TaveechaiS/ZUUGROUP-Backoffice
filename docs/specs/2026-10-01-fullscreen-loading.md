# TASK-059: Loading เต็มหน้าจอ

เจ้าของโครงการขอให้สถานะ Loading ขึ้นกลางหน้าจอระหว่างเปลี่ยนหน้าและระหว่างโหลดข้อมูล พร้อมไอคอนและแอนิเมชันที่ลื่นตา.

- ใช้ `LoadingComponent` กลางเป็นพื้นผิวเต็ม viewport พร้อม icon ที่เก็บใน `src/components/icons/`; ข้อความไทยบอกว่ากำลังโหลดข้อมูล.
- เมื่อ Next.js เปลี่ยน route ที่ต้องรอเนื้อหา ให้ `src/app/loading.tsx` แสดง Loading ตาม file convention ของ Next.js 16.3.6.
- การอ่าน session ใน RootLayout เป็นงาน async ที่เกิดก่อน route fallback จึงครอบส่วนนี้ด้วย Suspense และ Loading เดียวกันเพื่อแสดงสถานะระหว่างเข้าเว็บครั้งแรก.
- เมื่อ Client Component โหลดข้อมูลหลัก ให้แสดง Loading เดียวกันใน Dashboard, รายการโมดูล และหน้ารายละเอียดโมดูล; ปิดเมื่อข้อมูลพร้อมหรือเกิดข้อผิดพลาด เพื่อให้เห็น error/action ตามเดิม.
- การโหลดข้อมูลย่อยในฟอร์มไม่ใช้ฉากเต็มหน้าจอ เพราะผู้ใช้ยังทำงานกับฟอร์มได้.
- ภาพ: พื้นขาวโปร่งบาง, วงแหวนสีน้ำเงินและไอคอนข้อมูล, ข้อความสั้น. Motion: วงแหวนหมุนช้าและไอคอน/จุดสถานะเปลี่ยนความเข้มอย่างนุ่มนวล; ปิด motion เมื่อระบบตั้งค่า reduced motion.
- ใช้ Tailwind utility ใน `className`; ไม่แก้ `globals.css`, API, DB หรือกฎธุรกิจ.

ตรวจรับ: เมื่อเข้าหน้า/เปลี่ยนหน้าที่โหลดช้าเห็นสถานะกลาง viewport; ขณะรอ GET หลักเห็น overlay; เมื่อข้อมูลสำเร็จ overlay หาย; เมื่อผิดพลาด overlay หายและเห็น error; reduced motion ไม่มีการหมุน/กะพริบ.
