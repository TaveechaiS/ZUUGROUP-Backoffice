# ข้อกำหนด — จัดขนาดตัวอักษรตามสเกล Tailwind

**ที่มา:** คำขอเจ้าของโครงการ 2026-09-24

**Task:** TASK-023

- ตรวจขนาดตัวอักษรทุกจุดใน `src` ทั้ง Sidebar, Topbar, footer และ placeholder.
- ใช้คลาสชื่อขนาดของ Tailwind แทน `text-[...px]` ทั้งหมด โดยปัดขึ้นไปหาขนาดมาตรฐานถัดไปเมื่อไม่มีค่าตรงกัน.
- การจับคู่: 9/10/11px → `text-xs` (12px); 13px → `text-sm` (14px); 15px → `text-base` (16px); 17px → `text-lg` (18px); 21/23px → `text-2xl` (24px).
- ชื่อหน้า Topbar เป็นข้อกำหนดเฉพาะที่เจ้าของโครงการปรับภายหลัง: Desktop `text-xl` 20px และจอแคบ `text-lg` 18px; มีผลแทนการปัดค่าเดิม 23px ขึ้นเป็น 24px.
- คลาสที่เป็นมาตรฐานอยู่แล้ว เช่น `text-sm` หรือ `text-base` คงไว้.
- ใช้ความสูงบรรทัดตามค่าเริ่มต้นของคลาส Tailwind; ไม่เพิ่มคลาส line-height เพื่อชดเชยการเปลี่ยน.
- คงข้อความ, น้ำหนักอักษร, สี และส่วนอื่นของ UI.
