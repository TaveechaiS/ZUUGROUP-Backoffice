# ข้อกำหนดเพิ่มเติม — ภาพรวมหน้าระบบและหน้า Detail ตัวอย่าง

**วันที่:** 2026-10-01 (Asia/Bangkok)
**สถานะ:** เจ้าของโครงการอนุมัติให้ทำ Mock เพื่อเห็นภาพรวมและปรับดีไซน์ก่อนข้อมูลจริง
**อ้างอิง:** Project Specs §22.4, §22.5 และ TASK-040

- เพิ่มหน้าภาพรวมเส้นทางสำหรับดูหน้าที่มีอยู่ของ Phase 3–9 โดยไม่เพิ่มเมนู Sidebar หรืออ้างว่า Phase ธุรกิจเสร็จแล้ว
- เพิ่มหน้า Detail ตัวอย่างสำหรับลูกค้าและสินค้า เชื่อมจากแถวรายการและกลับไปหน้ารายการได้ ใช้เฉพาะข้อมูลที่ Mock ปัจจุบันมีอยู่
- รายการที่สร้างชั่วคราวในแท็บเดียวกันเปิดหน้า Detail ตัวอย่างได้; ไม่บันทึกฐานข้อมูลหรือ Storage ฝั่งเซิร์ฟเวอร์
- แสดงป้าย “ข้อมูลจำลอง” และข้อความเมื่อไม่พบรายการ; หน้าเหล่านี้ใช้ตรวจการจัดวางและการนำทางเท่านั้น
- ห้ามเพิ่มฟิลด์จริง, กฎธุรกิจ, API, migration, permission, การคำนวณเงินหรือสต็อก, หรือเมนู Sidebar ที่ยังไม่ได้ยืนยัน
- เมื่อได้รับข้อมูลจริง ต้องปรับ Specs/Plan รายโมดูลก่อนเชื่อมพฤติกรรมจริง
