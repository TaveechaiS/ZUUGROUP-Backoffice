# ข้อแก้ไข Specs — Admin จัดการรหัสผ่านผู้ใช้

**วันที่ได้รับคำยืนยัน:** 2026-09-30 (Asia/Bangkok)
**อ้างอิง:** SPEC-PROJECT-001 รุ่น 0.3, OPEN-14, G-04, TASK-035

## ข้อกำหนดที่เจ้าของโครงการยืนยัน

- Admin เป็นผู้ตั้งรหัสผ่านให้ผู้ใช้เมื่อสร้างบัญชี
- เมื่อผู้ใช้ต้องใช้รหัสใหม่ Admin เป็นผู้ตั้งรหัสใหม่ให้
- ไม่ส่งอีเมล ลิงก์เชิญ หรือลิงก์ตั้ง/รีเซ็ตรหัสผ่านให้ผู้ใช้ และไม่ส่งรหัสผ่านทางอีเมล

ข้อกำหนดนี้ระบุผู้รับผิดชอบในการตั้งรหัสผ่านและช่องทางที่ไม่ใช้เท่านั้น วิธีจัดเก็บ/ส่งรหัสให้ผู้ใช้อย่างปลอดภัย การบังคับเปลี่ยนรหัสเมื่อเข้าใช้ครั้งแรก และข้อกำหนดความซับซ้อนของรหัสผ่านยังไม่ได้กำหนดในคำตอบนี้ ห้ามอนุมานเพิ่ม.

## ส่วนที่ยังเปิด

OPEN-14 และ G-04 ยังไม่ผ่าน เพราะยังต้องสรุปการจัดการ Admin คนสุดท้าย การสร้าง/ลบ Admin และวิธีกู้คืนเมื่อไม่มี Admin เข้าใช้ได้ รายละเอียดล่าสุดอยู่ใน [ทะเบียนการตัดสินใจ](../DECISIONS.md) และ [Project Plan](../plans/2026-09-23-1635-project-plan.md).
