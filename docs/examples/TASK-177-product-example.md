# ชุดข้อมูลสินค้าเพื่อทดลองกรอก

ข้อมูลสมมติสำหรับทดสอบระบบ ไม่ใช่ทะเบียนหรือข้อมูลสินค้าจริง. ไม่ได้บันทึกให้อัตโนมัติ.

| ช่อง | ค่าแนะนำ |
|---|---|
| กลุ่มรหัส | SUP — เวชภัณฑ์ |
| รูปแบบรหัส | OTH — อื่น ๆ |
| เลขลำดับ | ใช้เลขถัดไปที่ระบบโหลดให้ แก้ได้แต่ห้ามซ้ำ |
| ชื่อสินค้าเต็ม (ไทย) | สำลีแผ่นทดสอบ 100 แผ่น |
| ชื่อสินค้าเต็ม (ภาษาอังกฤษ) | Demo Cotton Pads 100 Pieces |
| ชื่อการค้า | Demo Cotton |
| ยี่ห้อ | แบรนด์ตัวอย่าง A |
| ประเภทผลิตภัณฑ์ | เครื่องมือแพทย์ (ตัวอย่างการเลือก ไม่ใช่การรับรองประเภทจริง) |
| หมวดหมู่สินค้า | เพิ่มหมวด “เวชภัณฑ์ทดสอบ” รหัส DEM ในตั้งค่าระบบก่อนเลือก หากยังไม่มี |
| หน่วยสินค้า | กล่อง |
| บริษัทผู้ผลิต | บริษัทผู้ผลิตตัวอย่าง A |
| ราคาขาย | 35.00 |
| รายละเอียดสินค้า | ชุดข้อมูลสมมติสำหรับทดลองบันทึกสินค้าและไฟล์แนบ |
| ประเภทตามกฎหมาย | ยังไม่ระบุ / รอตรวจสอบ |
| ตัวยาสำคัญ/ความแรง/รูปแบบยา/ทะเบียน/สรรพคุณ/คำเตือน/เงื่อนไขสั่งจ่าย | เว้นว่าง เพราะตัวอย่างนี้ไม่ใช่ยาและไม่ใช้ข้อมูลทะเบียนปลอม |
| รูปสินค้า | รูป JPEG/PNG/WebP/GIF สำหรับทดสอบ ขนาดไม่เกิน 10 MB ต่อไฟล์ |
| เอกสารแนบ | PDF หรือรูปสำหรับทดสอบ ไม่เกิน 10 MB ต่อไฟล์ |

หลังบันทึก: เปิดรายละเอียด/รีเฟรช ข้อมูลกับไฟล์ต้องยังอยู่ คงเหลือเริ่ม0เพราะยังไม่ได้รับสต็อก. รหัสเต็มใช้SUP-OTH-เลข5หลักที่เลือก. ไม่กรอกต้นทุนหรือภาษีในเพิ่มสินค้า: ต้นทุนกำหนดตอนรับสินค้าเข้า ภาษีตอนทำเอกสารตามTASK180.
