# คู่มือใช้งาน ZUUGROUP / User Manual

ฉบับ 3 ตุลาคม 2569 — อธิบายระบบปัจจุบัน ใช้คู่กับ [รายการตรวจรับรวม](UAT-PREPARATION.md)

## 1. เข้าสู่ระบบและเลือกเมนู

เปิดเว็บที่ผู้ดูแลให้ไว้ หรือ `http://localhost:5000` เมื่อเปิดระบบในเครื่อง. เข้าด้วยบัญชีของคุณ แล้วเลือกเมนูด้านซ้าย; มือถือเปิดเมนูจากปุ่มเมนู. สิทธิ์ที่เห็นขึ้นกับบัญชี Admin, Manager, Sales หรือ CFO. ใช้ปุ่มออกจากระบบเมื่อเลิกใช้งาน.

บางหน้ามีอยู่แต่ซ่อนจาก Sidebar เช่น ผู้ขาย ค่าใช้จ่าย ตรวจนับ และรายงานการเงิน. ดูเส้นทางในแบบฟอร์มข้อกำหนดหรือใช้ลิงก์ที่ผู้ดูแลให้เมื่อมีสิทธิ์; การไม่เห็นเมนูไม่ได้แปลว่าโมดูลนั้นไม่มี.

หากเข้าไม่ได้ ตรวจอีเมล/รหัสผ่านและข้อความที่แจ้ง. หากระบบเชื่อมต่อไม่ได้ให้ลองใหม่เมื่อเครือข่ายพร้อม. การตั้งรหัสใหม่ทำโดย Admin ตามระบบปัจจุบัน; ขั้นตอนกู้คืน Admin คนสุดท้ายอยู่ใน [คู่มือผู้ดูแล](runbooks/admin-account-recovery.md).

## 2. ค้นหาและดูข้อมูล

1. เลือกหน้ารายการที่ต้องการ เช่น กลุ่มลูกค้า
2. พิมพ์ในช่องค้นหา แล้วรอข้อมูลในตารางโหลด; ตัวค้นหายังคงอยู่บนหน้า
3. เลือกตัวกรองที่หน้ามีให้ใช้ แล้วเปลี่ยนหน้าด้วยปุ่มแบ่งหน้า
4. คลิกข้อมูลบริเวณแถวเพื่อเปิดรายละเอียด ไม่จำเป็นต้องคลิกเฉพาะชื่อ; ปุ่มคำสั่งในแถวยังคงทำงานของปุ่มนั้น
5. ข้อมูลที่ไม่มีจะแสดง `-`. เมื่อไม่พบรายการ ระบบแสดงสถานะไม่พบข้อมูล ให้ล้างคำค้น/ตัวกรองเพื่อตรวจอีกครั้ง

การเปิดหน้า/โหลด session ใช้ Loading เต็มจอ ส่วนค้นหา/เปลี่ยนตัวกรองใช้ Loading ในพื้นที่ข้อมูล. วันที่แสดงตามรูปแบบไทย พ.ศ. และเขตเวลา Asia/Bangkok. Header เลื่อนตามหน้า.

## 3. เพิ่มรายการ

1. ใช้บัญชีที่มีสิทธิ์ แล้วกดปุ่มเพิ่มของหน้ารายการ
2. กรอกช่องบังคับให้ครบ; ช่องสัมพันธ์ให้เลือกจากตัวเลือกในระบบ
3. กดบันทึก รอผลโดยไม่กดซ้ำ
4. เมื่อสำเร็จจะมีข้อความสำเร็จและปุ่มดำเนินการต่อ; ปิดข้อความหรือใช้ปุ่มที่แสดงเพื่อไปยังข้อมูล
5. หากไม่สำเร็จอ่านข้อความและแก้ช่องที่เกี่ยวข้อง. หากระบบแจ้งว่าอาจบันทึกแล้วแต่ไม่ได้รับผล ให้ตรวจรายการก่อนเพิ่มซ้ำ

ฟอร์มของแต่ละโมดูลต่างกัน ดู [แบบฟอร์มข้อกำหนด](BUSINESS-REQUIREMENTS-WORKBOOK.md) สำหรับรายชื่อฟิลด์ปัจจุบัน. ชื่อสถานะที่กรอกไม่ทำให้ระบบอนุมัติ/คำนวณเงิน/ปรับคลังเอง.

## 4. แก้ไขและยืนยัน

เปิดรายละเอียด แล้วกดแก้ไขข้อมูล. เปลี่ยนฟิลด์และกดบันทึก; เมื่อมีหน้าต่างยืนยัน ให้ตรวจข้อความก่อนกดยืนยันบันทึก.

- ยกเลิกในหน้าต่างยืนยัน: ยังไม่บันทึก และข้อมูลที่กรอกยังอยู่ในฟอร์ม
- ยืนยัน: ส่งข้อมูลและแสดงผลสำเร็จเมื่อบันทึกเสร็จ
- ข้อมูลถูกแก้ไขแล้ว: เปิดรายการใหม่เพื่อตรวจค่าล่าสุดก่อนแก้ต่อ ไม่กดทับโดยเดาค่าเดิม
- ยกเลิกที่ตัวฟอร์ม: กลับตามการนำทางของหน้านั้น ไม่ใช่ปุ่มยกเลิกของหน้าต่างยืนยัน

## 5. ลบและกู้คืน

คำสั่งข้อมูลกลางใช้สิทธิ์ Admin. เปิดรายละเอียด ตรวจว่าเป็นรายการที่ต้องการลบ แล้วกรอกเหตุผลตามช่องที่มีและกดลบ. หน้าต่างยืนยันแสดงชื่อรายการ; ยกเลิกจะไม่ลบ. เมื่อยืนยันสำเร็จรายการถูกซ่อนจากรายการปกติ.

กู้คืนจากแท็บ **ลบแล้ว** ของหน้ารายการที่รองรับ. ตรวจรายการแล้วกดกู้คืน รอผลสำเร็จ จากนั้นกลับแท็บปกติเพื่อตรวจข้อมูล. การกู้คืนข้อมูลไม่ใช่การย้อนยอดเงินหรือ Ledger. ไม่กดลบข้อมูลจริงเพื่อทดลอง; ใช้รายการทดสอบที่สร้างเองตามรายการตรวจรับ.

## 6. สินค้าและตัวเลือกคลัง

หน้า **สินค้า** ใช้เพิ่ม/ดู/แก้ตามสิทธิ์. ฟอร์มเพิ่มเลือกหมวด รูปแบบยา ตัวยา และคลังที่เกี่ยวข้อง พร้อมเลขลำดับ 4 หลัก ชื่อ หน่วย ราคาขาย และสถานะ. ตรวจรหัสที่ฟอร์มแสดงก่อนบันทึก.

ตัวเลือกคลังมาจากข้อมูลในระบบ; ยังไม่มีหน้า CRUD คลังแยก. รายการสินค้าเป็นข้อมูลหลัก ไม่ใช่ยอดคงเหลือ Lot หรือการเคลื่อนไหวคลัง.

## 7. ผู้ใช้และประวัติ

Admin เปิด **ผู้ใช้งาน** เพื่อเพิ่มบัญชี/แก้ข้อมูล/บทบาท/ตั้งรหัสตามหน้าจอ. ฟอร์มเพิ่มมีชื่อ อีเมล ทีม/เขต บทบาท และรหัสผ่านครั้งแรกขั้นต่ำ 8 ตัวอักษร. ระบบสร้างรหัสพนักงานให้. ห้ามใช้บัญชีจริงเป็นข้อมูลทดลอง.

ระบบป้องกันการลบตนเองและ Admin คนสุดท้าย. ปุ่มหรือคำสั่งที่ถูกปฏิเสธจะแจ้งเหตุผล; อย่าลบบัญชีอื่นเพื่อหลบเงื่อนไขนี้. เปิด **Audit Logs** ด้วยบัญชีที่มีสิทธิ์เพื่อดูผู้ทำรายการ การกระทำและเวลา; ใช้ตัวกรองที่มีในหน้า.

| เอกสารลูกค้า / ภาพรวมลูกค้า | เก็บรายการเอกสารและข้อมูลติดตาม                             |

| ค่าใช้จ่าย / จัดซื้อ        | เก็บหัวรายการและจำนวนเงินที่กรอก                            |
| ใบเสนอราคา / คำสั่งซื้อ     | เก็บหัวเอกสารและข้อมูลเกี่ยวข้อง                            |
| วางบิล / โปรโมชัน           | เก็บหัววางบิลและรายละเอียดโปรโมชัน                          |
| ตรวจนับสินค้า               | Admin คีย์ผลนับ Manual เพื่อเทียบข้อมูล ไม่ปรับยอดอัตโนมัติ |
| ตั้งค่าระบบ                 | เก็บรายการค่าตั้ง ไม่เปลี่ยนการตั้งค่า Auth อัตโนมัติ       |

## 9. Dashboard และรายงาน

Dashboard แสดงข้อมูลจากต้นทางตามที่มี; แผน API Dashboard ใหม่ยังพัก. รายงานปัจจุบันอ่าน:

- รายงานยอดขาย: รายการ/ยอดหัวคำสั่งซื้อ ไม่ใช่ยอดขายรับรู้
- รายงานการเงิน: หัวเอกสารวางบิล ไม่ใช่ลูกหนี้สุทธิหลังรับชำระ
- รายงานคลัง: ข้อมูลหลักสินค้า ไม่ใช่ยอดคงเหลือ/Lot

สูตรเงิน การอนุมัติ การรับชำระและ Ledger ที่รอกฎธุรกิจ ยังต้องยืนยันในแบบฟอร์มข้อกำหนดก่อนพัฒนาต่อ.

## 10. เมื่อพบปัญหา

| อาการ            | วิธีดำเนินการ                                                             |
| ---------------- | ------------------------------------------------------------------------- |
| ไม่พบข้อมูล      | ล้างค้นหา/ตัวกรอง ตรวจแท็บ และตรวจรหัสรายการ                              |
| ไม่มีสิทธิ์      | ให้ Admin ตรวจบัญชีและบทบาท; ไม่ถือว่าการเห็นเมนูเท่ากับมีสิทธิ์ทุกคำสั่ง |
| รหัสซ้ำ          | ตรวจรายการเดิมก่อนสร้างใหม่ แล้วใช้รหัสที่ถูกต้อง                         |
| มีผู้แก้พร้อมกัน | เปิดข้อมูลล่าสุดแล้วเทียบค่าก่อนบันทึกใหม่                                |
| เชื่อมต่อไม่ได้  | ตรวจเครือข่าย แล้วใช้ปุ่มลองใหม่ที่หน้ามีให้                              |
| ถูกพากลับ login  | เข้าสู่ระบบใหม่เมื่อ session หมดอายุ                                      |

เมื่อรายงานปัญหา ส่งชื่อหน้า ขั้นตอน ผลคาดหวัง ผลจริง และภาพที่ไม่มีข้อมูลลับ ไม่ส่งรหัสผ่าน/secret key.
