# ทะเบียนประเด็นรอตัดสินใจ

เอกสารนี้รวบรวมเฉพาะประเด็น `OPEN` จาก [Project Specs](specs/2026-09-23-1550-project-specs.md) รุ่น 0.2 เพื่อเชื่อมกับ Gate ใน [Project Plan](plans/2026-09-23-1635-project-plan.md) รุ่น 0.1

สถานะของทุกข้อด้านล่างคือ **รอคำตอบจากผู้ใช้** ห้ามใช้ข้อมูลจำลองหรือข้อสันนิษฐานแทนคำตอบ และห้ามเปิดงานที่ต้องพึ่งกติกานั้นก่อน Gate ที่เกี่ยวข้องผ่าน

## กติกาการปิดรายการ

1. บันทึกคำตอบของผู้ใช้โดยอ้างอิงวันที่และขอบเขตที่ชัดเจน
2. ปรับสถานะ Gate ที่เกี่ยวข้องใน Task ที่จะเริ่ม ไม่เปลี่ยนกฎในเอกสารนี้จากการตีความเอง
3. เมื่อมีคำตอบแล้ว จัดทำ Specs รายโมดูลที่เกี่ยวข้องก่อนเปิด Task เขียนโค้ดที่มีความเสี่ยง
