## กติกาการปิดรายการ

1. บันทึกคำตอบของผู้ใช้โดยอ้างอิงวันที่และขอบเขตที่ชัดเจน
2. ปรับสถานะ Gate ที่เกี่ยวข้องใน Task ที่จะเริ่ม ไม่เปลี่ยนกฎในเอกสารนี้จากการตีความเอง
3. เมื่อมีคำตอบแล้ว จัดทำ Specs รายโมดูลที่เกี่ยวข้องก่อนเปิด Task เขียนโค้ดที่มีความเสี่ยง
