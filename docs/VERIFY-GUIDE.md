# คู่มือตรวจโครงการ

หลังติดตั้ง dependencies ด้วย `npm ci` และเตรียม environment ตาม README ให้รันจากโครงการ:

```sh
npm run verify
```

คำสั่งตรวจตามลำดับ: ESLint → Next typegen → TypeScript → API contracts → pagination → route pages → resource API → API field names → production build รวม 9 ขั้นตอน

แต่ละขั้นแสดงชื่อและเวลาที่ใช้ หากไม่ผ่านจะหยุดทันที พร้อมชื่อขั้นและ exit code ไม่เป็นศูนย์ เมื่อผ่านทั้งหมดจะแสดง `ผ่าน 9/9 ขั้นตอน` กด Ctrl+C เพื่อหยุดชุดตรวจ

ชุดตรวจ API ทั้ง 5 ชุดใช้ข้อมูลจำลองหรืออ่านไฟล์ ไม่เรียก API จริงและไม่เชื่อมฐานข้อมูล คำสั่งนี้ไม่รัน migration, seed หรือแก้ข้อมูลธุรกิจ ทั้ง Next typegen และ build สร้างไฟล์ในเครื่อง; build อาจต้องใช้อินเทอร์เน็ตเพื่อโหลดฟอนต์เมื่อยังไม่มี cache จึงไม่รับประกันว่า verify ทั้งชุดจะทำงาน offline

อย่ารันพร้อม dev/build/verify อีกชุดที่เขียน `.next` เดียวกัน หากขั้นใดล้มเหลวให้แก้สาเหตุจากผลขั้นนั้นแล้วรันใหม่ ไม่ควรลด assertion เพื่อให้ผ่าน

## ตรวจแผน seed เพิ่มเติม

```sh
npm run verify:seed
```

เป็นชุดตรวจแยก ไม่รวม 9 ขั้นตอนข้างต้น ต้องมี `scripts/snapshots/TASK-076-before.json` จาก TASK-076 ในเครื่อง หากไม่พบจะขึ้นข้อความและจบด้วย exit code 1 โดยไม่ข้ามการตรวจ ชุดนี้จำลองแผนและตรวจ SQL ในหน่วยความจำ ไม่เขียนฐานข้อมูล ห้ามนำ snapshot ที่มีข้อมูลเฉพาะเครื่องเข้า Git

## ⚠️ ต้องทดสอบโดยคุณ

รัน `npm run verify` ควรแสดงผ่าน 9/9 หากพบข้อผิดพลาดควรหยุดที่ขั้นนั้นและไม่เริ่มขั้นถัดไป การผ่านชุดนี้ยังต้องตรวจการใช้งานจริงและหน้าจอตามรายการตรวจรับของแต่ละ Task
