# สถานะหน้าที่แสดงข้อมูล

ใช้มาตรฐานนี้กับทุกหน้าและกล่องข้อมูล รวมหน้าใหม่:

- กำลังโหลด: `LoadingComponent`. ตารางใช้ `variant="content"` ในกรอบ `relative` ที่มีความสูงขั้นต่ำ; ทั้งหน้าใช้ค่าเริ่มต้นหรือ `src/app/loading.tsx` ที่สืบทอด.
- โหลดสำเร็จแต่ไม่มีรายการ/ค้นหาไม่พบ: `NotFoundComponent` พร้อมข้อความตามข้อมูลของหน้านั้นและปุ่มลองใหม่ที่โหลดข้อมูลใหม่.
- ไม่พบ ID (HTTP 404): `NotFoundComponent`; SSR `notFound()` ใช้ `src/app/not-found.tsx`.
- ข้อผิดพลาด: คง error/ปุ่มลองใหม่. ไม่ใช้ NotFound แทน 401/403/500/503 และไม่แสดง empty ซ้อน loading.

หน้าตัวอย่างหรือฟอร์มที่ไม่มีการโหลดข้อมูลไม่ต้องเพิ่ม loading/empty ปลอม. ใช้คอมโพเนนต์กลางโดยตรง รักษาข้อความและค่าธุรกิจเดิม.
